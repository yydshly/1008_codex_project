# 图片与素材

保存 __NAME__ 的真实截图、架构图和演示素材，优先使用 `cover.png`、`architecture.svg` 等简短英文文件名。

- 项目 README 使用相对路径，例如 `assets/cover.png`。
- 首页封面在根 `projects.json` 中设置为 `projects/__ID__-__SLUG__/assets/cover.png`。
- 同时填写 `coverAlt`（画面内容）、`coverCaption`（图注，可包括场景和版本）。
- 引用上游图片时记录来源和许可，生成的图应说明其描述的是哪个版本。
- 每张图应有实际对应的文件；尚无图片时保留封面字段为空。
