# AiToEarn 能力与原理总览

固定研究：yikart/AiToEarn，3581f511293236044e56fad67958cfcea0def6b5，MIT，2026-10-09。图中结论来自本项目固定源码研究和真实图文调用记录；扩展方向为建议。此文是总览图的可搜索、可复制文字稿。

## 01 · 工作原理

定位：面向个人创作者、商家、品牌和代运营的内容营销系统，从真实素材连接内容创作、发布和运营。

- Agent：理解目标，选择与编排步骤。
- Skills：方法、参数、轮询和失败处理。
- Tools / MCP：调用模型、媒体加工与业务接口。
- Backend：保存素材、草稿、账号、排期和状态。

六层协作：目标与素材 → Agent调度 → Skills方法 → 工具执行 → 后台与队列 → 模型与渠道结果。长任务先返回任务ID后轮询；任务创建不等于最终发布。

技术组成：Next.js、Claude Agent SDK、Claude Code Router、NestJS、MongoDB、Redis/BullMQ、S3/RustFS、Sharp/ffmpeg、外部模型与云API。

## 02 · 全量能力：八个业务环节、32项

| 环节 | 条目 |
| --- | --- |
| 内容创作（5） | 标题正文话题；图片与参考图；文生/图生视频；批量草稿；历史偏好摘要 |
| 媒体加工（9） | 图片精确合成；轨道剪辑；多素材合成；视频理解/高光；翻译配音字幕；硬字幕擦除；风格转换；影视解说；封面/媒体探测 |
| 素材管理（3） | 社媒链接采集；媒体库分组；草稿与已有视频转草稿 |
| 发布与账号（5） | 账号分组授权；多平台流程；日历排期；规则/格式适配；状态与失败处理 |
| 互动运营（3） | 点赞评论收藏关注；AI回复/意向识别；品牌讨论监测 |
| 数据分析（2） | 账号与作品指标快照；作品查询与归属验证 |
| 集成与部署（4） | MCP助手；OpenClaw；私有部署；Server Relay/AI Relay |
| 推广变现（1） | 推广任务、提交与结算 |

AI回复、品牌监测和推广业务含官方描述，链路未全量实测；采集入口待核验。完整输入、实现与逐项边界见网页能力图谱。

## 03 · 技能与渠道

13个技能：图片生成、视频生成、图片编辑、视频剪辑、多素材合成、视频理解与高光、视频翻译、硬字幕擦除、视频风格转换、影视解说、媒体与草稿管理、视频封面、社媒内容采集。

14个声明支持渠道：抖音、小红书、快手、哔哩哔哩、微信视频号、微信公众号、TikTok、YouTube、Instagram、Facebook、Threads、X/Twitter、Pinterest、LinkedIn。

每个渠道的格式、授权和完成方式不同：API、插件或用户接续。不能把14个渠道理解为每种发布、互动与指标都能在所有渠道使用。

## 05 · 使用场景

- 项目研究：README、截图、录屏 → 知识图文与演示。
- 个人创作：主题和素材 → 一周草稿与排期。
- 品牌电商：真实产品和卖点 → 多场景宣传内容。
- 本地门店：现场照片和活动 → 图文与竖屏视频。
- 多语言传播：自有视频 → 翻译、配音与目标渠道。
- 代运营：多个项目或客户 → 素材、账号与交付记录。

## 06 · 对你的意义

把现有GitHub研究转成可传播内容；按项目编号保存来源、版本、素材和草稿；建立固定图文模板减少重复整理；学习Agent、Skills、工具和后台的分工；参考队列、轮询、重试和平台适配；以人工修改量、准备时间和真实反馈评估价值。

## 07 · 可扩展方向（建议，未实现）

1. 研究集接入：自动读取文档、来源与版本。
2. 模板化：统一封面、品牌样式和图文结构。
3. 视频化：接视频模型、自有录屏剪辑和字幕审阅。
4. 单渠道：账号授权、草稿审批、发布与结果回看。
5. 多项目：素材分组、预算、客户审核和任务队列。
6. 反馈闭环：渠道数据、内容对照和多语言复用。

## 08 · 接入条件与边界

技能文件需要真实工具、模型服务、存储和账号授权。当前采集缺工具、字幕注册被注释，封面技能有旧接口；批量不等于并行。历史偏好默认关闭，摘要不等于训练。抖音可能需要用户接续，小红书/视频号依赖插件。指标受平台及权限影响，成品、发布、转化和收入需要分别验证。扩展路线为本研究建议，不能当作原库已实现功能。
