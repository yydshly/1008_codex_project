01

能力是什么

加载与推理

使用已有权重回答问题、生成内容。

量化与运行

压缩权重，匹配 GGUF / 低精度后端。

LoRA / QLoRA

训练少量增量，定制任务、风格与输出习惯。

全参数微调

从已有权重开始，更新全部或大部分参数。

继续预训练

用原始语料继续学习领域表达与语言。

DPO / GRPO

用偏好样例或奖励调整行为；评分仍需设计。

多模态与导出

按模型支持处理视觉、语音、图像、音视频和向量任务；保存与部署结果。

总体能力来自不同工作流。不是每个模型、后端和硬件都支持每一种训练方法。

02

底层原理有哪些

低秩适配

W = W₀ + sBA；冻结基础参数，学习小增量。

QLoRA

基础权重量化存储，适配器单独训练。

Triton＋定制反向

融合热点运算，减少临时张量和内存搬运。

检查点 / 分块 / 卸载

重算或分段处理中间结果，降低显存峰值。

Padding-free / Packing

减少填充位置，正确保留训练样本边界。

RL 资源复用

交替安排生成与更新，复用权重并调度缓存。

MiniMax H3｜一个具体例子

专用音视频训练路径 · 固定提交 f9718db

运行现成能力

加载基础权重、编码器与 VAE，生成视频和声音。运行与微调是两套成本。

微调音视频

有有效音轨的视频＋文字描述 → 联合音视频 LoRA → 新适配器。当前固定 22 帧，约 0.92 秒；长片需切片对齐描述。

资源与精度边界

整流程资源参考约 80GB+，未本机实测。FP8 推理包不等于 FP8 可训练，当前训练配置有专门限制。

优点与实际价值

少显存

降低训练参数与中间结果的开销。

快迭代

减少重复计算，更快比较训练方案。

适配器复用

在兼容底座上保存不同任务的增量。

本地掌控

在合适硬件上保留数据与运行控制。

生态连接

衔接 PyTorch、Transformers、PEFT 和训练工具。

交付价值

把通用模型变成可评估的任务组件。

效率改善依赖模型、GPU、精度、长度与软件版本；效率提高不等于任务效果自动提高。

07

容易混淆的边界

  • 二次训练更新参数；二次开发编写接口、网页和业务流程。
  • 全参数微调仍可从旧权重开始，并不等于从零训练。
  • 上传文档不等于自动学会；知识检索通常不改权重。
  • 远程 API 不提供权重时，不能直接修改远程模型。
  • 量化文件体积不等于完整训练显存；工具和模型许可需分别核对。
