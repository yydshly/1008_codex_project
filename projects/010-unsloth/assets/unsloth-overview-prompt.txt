Unsloth 能力全景图的最终制作说明

目的：用一张可放大、可保存的高清中文图，汇总能力、原理、优点、模型、场景、价值、个人意义与使用判断。
事实输入：本项目固定提交 f9718db128218f43b7e0b03604baa4a9a6633028 的研究资料；本次补充核对官方模型目录和语音微调文档。
范围校正：微调也是训练。已确认加载、量化、LoRA / QLoRA、全参数微调、继续预训练和偏好 / 强化学习；不能写成“不支持训练模型”。通用随机初始化完整入口本次未核实，H3 已确认的现成路径为已有权重上的 LoRA。
布局：1600px 宽原创 HTML，奶白底、深绿标题、淡绿重点；八个编号模块、五步流程、单矩阵 LoRA 公式示意、H3 专栏、落地步骤与来源 / 许可页脚。无外部字体或图片，无模型生成效果样例。
模型清单：文本、专门架构、视觉、语音、图像、音视频、向量七类；代表型号不是全部支持清单；运行和训练能力须分别核对。
对个人意义：结合本仓库的 GitHub 研究、网页原型和内容制作；先接入与提示词，需要新事实时用检索，稳定重复任务有好数据时再微调；第一次选小模型、单一任务与独立测试集。
输出：Microsoft Edge / Playwright 加载真实 HTML 排版，以 1.5 倍像素比例导出单张 PNG。检查文字不溢出、八模块与七模型行完整、公式和限定条件存在。另人工查看真实图像。
内容文本与来源：unsloth-overview-content.md。

工具记录：曾尝试内置 image_gen，返回网络请求错误，没有得到生成图片。原始实际提示词保存在 unsloth-overview-imagegen-attempt.txt。最终采用本地原创排版，不使用备用 API 生图，不需要 API 密钥。
