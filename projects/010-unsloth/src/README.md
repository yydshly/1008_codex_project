# 实验范围

本次完成源码 / 文档研究与 `../web/` 中的原创网页，没有复制 Unsloth 上游实现，也没有执行 GPU 训练。本目录可放后续独立实验；真实模型实验需自行选择硬件和依赖，并记录上游模型版本、数据、许可与评估结果。

`verify-web.mjs` 是本项目原创的可选真实浏览器验证，检查生产页面、阅读交互、计算示意、移动排版和无脚本可读性；不调用模型。使用已有 Playwright 包，通过 `PLAYWRIGHT_PACKAGE` 指定包目录，可用 `BROWSER_CHANNEL` 选择已安装浏览器（默认 `msedge`），用 `PREVIEW_URL` 指定预览地址。没有把浏览器验证依赖加入网页的运行依赖。
