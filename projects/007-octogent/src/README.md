# 代码与许可范围

`../web/` 是独立编写的中文讲解与效果展示，不包含 Octogent 运行后端，不调用真实 AI。

`LICENSE.upstream` 是上游研究提交的 MIT 原文，保留从 hesamsheikh/octogent 引用的截图和 favicon 的许可。来源见 `../assets/README.md`。

`verification.json` 记录本网页实际检查结果。示例任务、分支、消息和测试结果是原创预设内容，不是原项目运行日志。

`render_understanding_map.py` 是原创制图脚本。使用 Pillow、微软雅黑字体和上游原图，生成高清 PNG、可编辑 SVG、预览图、中文文字版与章节坐标；不执行原项目。正文卡片检查文字溢出，PNG 与 SVG 共用同一布局。
