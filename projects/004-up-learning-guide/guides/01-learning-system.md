# 01 · 学习系统与方法原理

## 1. 将愿望转成可以验收的任务

“学好英语”“提升编程”“更自律”不能直接决定下一步。一个任务回答六类问题：

| 组成 | 应说明什么 | 完成证据 |
| --- | --- | --- |
| 受众 | 谁理解、使用或据此决定 | 对方收到的信息或完成的动作 |
| 行为 | 解释、回复、运行、比较、确认或交接什么 | 可保存的输出 |
| 输入 | 具体材料、版本与来源 | 原始位置与适用条件 |
| 门槛 | 关键质量和不可接受失败 | 行动前的标准 |
| 限制 | 时间、精力、设备、工具与责任 | 结果及获得的帮助 |
| 留证 | 保存什么、何时复查 | 首版、测试、反馈或回应 |

本研究设计的示例：二十分钟写一份项目更新，让同事无需开会就知道进展、阻塞、责任人和下次检查点；保留初稿与同事复述。它是解释方法的假设任务。

## 2. 不让三类信息互相替代

研究结论保留样本、条件、测量与来源；个人经验解释作者经历；假设需要反例、实验和截止日期。“采用后成功”不能排除运气、环境与其他变量；研究平均结果也不能保证个人效果。周期、时长、词块数与样本配比默认按教学设计理解。

## 3. 独立首版保护比较起点

在AI、翻译、答案或润色介入前完成一次，保存材料、时限、允许工具、未知项和位置。不要用修订覆盖首版，也不必公开它。一次失败受题目、设备、背景和容量影响，不是永久能力判决。后续尽量固定主要条件，换同难度平行任务。真实高风险工作中的必要核验不能为了训练而撤掉。

## 4. 定位可改变的错误

| 层次 | 典型障碍 | 第一项修复 |
| --- | --- | --- |
| 语言形式 | 声音、词形、语法或拼写不识别 | 一个改变意思的形式 |
| 结构意义 | 条件、指向、时间或责任不清 | 句块、关系与意义对比 |
| 背景概念 | 字认识，领域前提不懂 | 一小段可信先修知识 |
| 策略工具 | 查阅无尽，提示撤不掉 | 最小支架与撤架条件 |
| 注意容量 | 后半段出错，负荷过大 | 长度、时段与任务量 |
| 环境设备 | 噪声、网络、字体影响结果 | 先排除环境故障 |

“粗心”“没天赋”不能直接训练。每轮选一至三个高影响问题，下一周期尽量只改一个主要条件。

## 5. 一次有限练习的六步

说明任务、受众和门槛；保留首版；诊断障碍；补最少必要材料；合上资料主动解释、写作、说话或运行；核对反馈并记录下一步。上游给出二十五至四十五分钟窗口，容量不足可缩小。

课程收藏、划线、视频时长、卡量与打卡属于过程。它们只有帮助决定继续、调整、降档或停止时，才值得长期追踪。

## 6. 回忆、间隔与交错

主动回忆在答案不展示时调用：闭卷摘要、解释概念、复现运行步骤、在新场景用词块。困难应暴露可修复缺口，不能始终简单，也不必困难到完全失败。

当天、次日、三至七日、十四日、三十日可作为复查提醒，不是固定遗忘日历。稳定且迁移成功时延长；费力成功时保持；反复失败时拆小或补先修知识；认得出却用不出时增加产出；无关内容可归档。

交错让不同情境中的知识相互辨别，但过多变量同时变化会妨碍解释。睡眠、饮食、身体与恢复决定可用容量。上游引用相关学习研究，本研究未重新实施实验。

## 7. 反馈进入下一任务

先看受众能否复述主旨、依据和行动，再处理形式。修改应区分事实错误、歧义、语域、可接受变体与风格。采纳、部分采纳、拒绝或延后均应给理由。

把一条反馈转成平行任务的检查条件；让旧稿漂亮还不证明会迁移。两个AI重复意见不等于两份独立事实来源。

## 8. 四个时间点构成证据链

| 时间点 | 要回答什么 | 留什么 |
| --- | --- | --- |
| 基线 | 本轮帮助前能做什么 | 原样本与条件 |
| 即时表现 | 练习后改变了什么 | 帮助、修改和测试 |
| 延迟保持 | 过几天撤掉提示还会什么 | 独立平行样本 |
| 迁移 | 换条件还能否应用 | 变化条件、新结果与错误 |

保持检查时间变化，迁移检查情境变化。比较分数必须同时说明工具、材料与评价条件。分别记录事实、解释和假设：测试通过是观察；能力更可靠是解释；换客户也会成功是待检验判断。单人的一轮对照不能证明因果，但能帮助下一决策。

## 9. 注意力与环境

输入前问是否关联当前问题、来源是否值得核对、会挤掉什么。使用AI前先留下自己的判断；减少通知，提前放好一份材料，记录临时念头，明确结束时间。专注也影响关系，需要说明可联系时段、紧急入口与返回时间。每周审计只找一个反复阻力，避免把每分钟变成监控对象。

## 10. 文件状态与跨会话交接

状态页保存目标、限制、基线、已完成、错误、有效方法、假设、最近交接和下一步；完整作品与历史另存。新会话先读最新状态、复述并指出冲突，再处理一项任务，结束时输出人工可核对的更新。

学习状态负责现在；证据链负责变化；周复盘负责下一变量；九十日总表负责周期；任务简报负责本次工作。模型摘要仍要与作品、来源及版本比较。跨会话延续依赖读者维护的文件，不产生平台永久记忆。

## 11. 一周、三十天与十二周

第一周检查任务、材料与回归成本；三十天比较同类任务、建立错误库并删无效步骤；十二周加入真实受众和条件变化。周期可以调整，不保证升级速度。最小记录只要问题、现有样本、今天输出、证据位置；复查完成、质量、保持和迁移，决定保留、改动和停止。

## 12. 两种读法

沿主线阅读理解作者经历与方法来路；按当前问题进入一章、一张工作纸，行动后返回主线。没有作品先处理交付；记录多却看不见变化先处理证据；低容量先缩小；帮助孩子先确定共同职责；求职先用岗位任务诊断。

可迁移的核心是任务、基线、反馈、撤架、迁移与状态。故事、合成演示与日程提供线索，效果由自己的样本继续检验。
