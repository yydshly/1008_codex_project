本篇对应第一部全部十一页。上游提供训练框架，不包含全部英语语法、全部词义或完整考试课程。以下为研究改写，各技能配套原文与工作纸入口保留在完整目录。

## 1. CEFR：用可完成任务描述起点

| 方向 | 上游简化说明 |
| --- | --- |
| A1 | 在慢速和协助下完成极基础理解与互动 |
| A2 | 处理购物、地点、工作等熟悉场景的直接交流 |
| B1 | 理解熟悉主题主旨，说明经历、计划与理由 |
| B2 | 处理复杂观点，较自然参与讨论并表达立场 |
| C1 | 理解要求高的长材料，灵活处理职业与学术表达 |
| C2 | 综合不同来源，重构观点并表达细微差别 |

这是训练方向，不是正式测试，也不能从词量、App积分或学习小时数直接换算。听、读、说、写分别保存基线，不强制平均定级。

上游的启动样本包括：听短音频后记主旨与细节；读文章后摘要和质疑；不读稿录音；限时邮件或短文。按任务完成、可理解度、准确与范围、组织流畅、修订迁移比较。0—2量表用于个人纵向观察，不是统一认证。

协作另看转述与调解、在线互动、误解修复：能否保留不同立场，说明线程中的进展阻塞负责人，澄清后确认共识。它们是任务维度，不增加语言等级。

目标需同时包含场景、任务、质量、期限和证据。7天启动基线，30天比较同类任务，12周进入真实交付。来源：[CEFR自测](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/threads/part-1/0-cefr.md)。

## 2. 词汇：从认识到情境调用

### 按任务挑词

会议需要识别决定和责任；文档需要当前术语与限制；口语需要限时检索；邮件需要准确义项、搭配和关系语气。首遇先不查所有词，保存原理解及阻断位置。

未知项可作五种决定：不影响主线的略过；有线索的推断并标置信度；当前必要但长期价值低的速查；重复且很快要用的主动学习；涉及高影响专业责任的回到一手定义核验。一轮只选少量高价值词块。

### 八维词汇知识

| 维度 | 检查内容 |
| --- | --- |
| 词形 | 拼写、屈折、派生、词性 |
| 声音 | 重音、音素与连读中的识别 |
| 当前义项 | 当前句法和语境中的意思 |
| 搭配词块 | 常共同出现并完成意义的组合 |
| 语法行为 | 接什么结构，有何限制 |
| 语域语用 | 正式程度、礼貌、态度、受众 |
| 概念指代 | 对象、制度、领域与版本是否相同 |
| 调用条件 | 能否无提示限时使用，是否依赖原句 |

词族有助分类和估算，不意味着每个派生形式自动掌握。查词要保存原句，核对适用义项、搭配、反例和来源；技术与制度词回到当前领域定义。

### 接受、产出与覆盖率

阅读认识、原音听出、主动说出、写得准确是不同能力。可以从解释原句，进入闭卷调用、改变人物或语气，再交给真实受众验证。

95%或98%运行词覆盖率描述已知词比例，不等于理解比例；关键未知词、句法、背景和体裁会影响结果。研究中的词族数量依赖语料、计数单位和理解前提，不能转成所有人的统一目标。上游撤掉了“固定词量等于固定理解百分比”的旧说法。

### 卡片与复查

卡片测试一个情境决定，保留出处、第二场景和反例。长卡容易变重读，固定原句容易阻碍迁移。听不出加音频；义项混淆加对比；真实使用慢就做限时说写；不相关可归档。

间隔按表现变化：稳定且可迁移则拉长，费力成功可保持，反复失败则拆小、减量或补背景。Anki等工具安排日程，不能用卡量证明能力。AI可以给候选和变式，义项搭配仍由词典、语料及当前文档核验。

上游的35分钟练习安排任务、首遇、未知项决策、查证、变式输出和记录；14天实验再加入跨模态、受众反馈、归档、语域变化及撤掉旧卡后的平行任务。来源：[词汇篇](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/threads/part-1/2-vocabulary.md)。

## 3. 语法：结构怎样改变意思

六类意义选择包括参与者责任、时间状态、对象数量、否定提问、逻辑关系、确定性态度。语法首先保证听众知道现实是什么；把句子变长不等于更好。

优先修改变意思、阻断任务或跨样本反复出现的错误；语域不合其次，低影响偏差可以后置。六块基础是句子骨架动词、提问否定、时间与体、名词冠词可数性、从句逻辑、情态缓和。

练习顺序：观察自己的错误和真实例句；一句话说明结构意义；只改一项条件做形式对比；闭卷情境选择；回到说写；几天后新主题复测。意义对比卡保留意图、易混形式、原句、错误、修改理由、反例与复测。

听读识别时间指向范围，说写练现场调用与修订。反馈先解释原句被怎样理解、哪个结构造成差异，再给修正。AI建议要区分明确错误、歧义、语域和风格，重要判断由可靠资料或真实受众复核。14天只追踪一个高影响结构。来源：[语法篇](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/threads/part-1/grammar.md)。

## 4. 听力：从声音到理解的六层诊断

听力任务可分主旨、细节、关系、执行、互动和迁移。首听记录来源、设备、主题口音熟悉度、速度、暂停字幕与重播；之后保存主旨、确定细节、态度、不确定时间段与行动。

| 障碍层次 | 修复方向 |
| --- | --- |
| 技术环境 | 先排除失真、噪声、延迟与音源问题 |
| 语言未知 | 补最小词义或结构 |
| 已知未听出 | 查连读、弱读、重音和词界 |
| 结构指向 | 画代词、条件、转折与责任关系 |
| 背景推断 | 补少量可信事件或专业前提 |
| 注意容量 | 缩短材料、减笔记负荷、换时段 |

材料需要可切分、可核对、略有挑战且值得重复；一份主材料修问题，一份平行材料测方法。自动字幕会错术语和数字，不能默认正确。

支架阶梯：无字幕首听；缩到问题片段；用英文转写核对；只查必要信息；关文字回正常速度；延迟后换材料。五遍分别预测首听、定位差异、最小修复、关闭支架、意义重构与行动。

听写只处理改变结果的关键片段。朗读与延迟跟读之后，要闭卷关键词复述、改变事实、回答陌生追问。精听修细节，泛听建耐力，休闲接触不必全部任务化。

迁移逐项换主题、说话者、口音、速度、设备、噪声或多人轮换。真实工作可以继续用转写、聊天确认和会后总结，分别记录有帮助与撤掉后的表现。14天覆盖首听、诊断、修复、重构、追问、撤架和条件变化。来源：[听力篇](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/threads/part-1/3-listening.md)。

## 5. 阅读：把主张变成证据和行动

定位信息、理解论证、运行文档、长文耐力、多来源比较与决策需要不同精度。保存作者、版本、日期、限时、工具及首读结果，不让翻译后摘要覆盖起点。

六层障碍为词汇语法、结构指向、背景图式、论证证据、版面技术、注意容量。每层应有不同修复：读得出字却不懂领域，与PDF代码折行错误不是同一问题。

五遍依次定位方向；标段落功能和骨架；核对关键证据；合上工具重构问题、主张、理由与限制；完成实际输出。多来源比较保留立场、时间、适用条件和分歧。

技术文档按目标、版本、前置条件、最小示例、参数约束、失败回滚、实际验证阅读。事实卡记录最小输入、预期输出、实际结果、错误信息、明确限制、个人推断和出处。结果不符时分开版本、环境、理解与文档问题。

精读修细节，泛读建耐力，窄读复用同主题背景。翻译和AI摘要可以辅助地图，关键否定、条件、责任与引用要回原文。阅读输出可是一页比较、确认邮件、风险说明或运行样例。14天加入首读、关系与证据地图、修复、真实输出、平行材料及撤架。来源：[阅读篇](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/threads/part-1/4-reading.md)。

## 6. 口语：听众理解和互动修复

先指定听众、场景、时长、稿件限制和行动。样本覆盖无稿独白、问答及信息解释/转述，记录听众真实收到什么。

参考变体只用于建立一致参照。口音显著度、可理解度、理解难度必须分开：声音不同不自动妨碍任务；转写成功也不能认证自然发音。可以用不同听众、设备和主题核对。

优先修影响词义、数字、时间、数量与重点的声音、词尾、重音、句块和语气。听辨、观察动作、慢说、短句、陌生句逐级练；孤立词准确而自然句丢失时看节奏与调用。

听标记、朗读、延迟跟读、闭卷复述再到陌生追问。可替换词块比整篇固定稿更易迁移，每个都换主题、立场或听众。互动修复包括请求重复、确认范围、争取思考、换表达、总结共识。

真实听者验收意思，教师定位可教问题，AI提供转写候选和追问；模型、设备、噪声造成的问题单列。短练习连接无稿首版、回听、小修复、重录和追问，14天加入撤稿与听众设备变化。流畅不是取消所有停顿，而是能继续共同理解。来源：[口语篇](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/threads/part-1/5-speaking.md)。

## 7. 写作：事实、修订和可署名交付

说明、请求、状态、决策、叙事、反思与交接各有标准。先限时自己起草，记录真实受众、关系、来源、允许工具和署名边界。

事实责任账本分可查事实、数字口径、引语、经历、推断建议、他人信息，保留版本位置、核验、权限与未知。段落分别承担背景、回答、依据、例子、限制或下一步。

翻译用母语意图、英文首版和最终选择作对照，检查主体责任、确定性、条件否定、礼貌和概念是否变化。

五次修订按任务事实、结构证据、句子意义、语域声音、交付边界展开；最后验证链接、附件、权限与负责人。反馈先复述主旨、依据和下一步，再给高影响诊断；记录采纳与拒绝并写平行文本。

AI可模拟读者、分类问题和比较版本；虚构经历、隐形代写、不存在的来源不能作为学习证据。异步文档写清结论、已完成证据、风险阻塞、决定人与截止、后续负责人和无回应处理。交接加版本、环境、失败回滚与复查点。14天保留初稿、来源、骨架、意义对照、反馈吸收和新任务撤架。来源：[写作篇](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/threads/part-1/6-writing.md)。

## 8. AI辅助英语：分清学习与工具错误

每次卡固定任务、自己的首版、可信材料、允许帮助、反馈和撤架时间。AI先让学习者答，再解释一至三个高影响问题、给最小提示与平行题。

文件问答、引用研究、语音、写作反馈和项目空间承担不同功能。上游列举工具入口，不提供稳定排名；当前功能与规则需另外核对。目标和证据保存在可导出的文件中。

跨模态练习可从图表无辅助解释开始，再核对图中依据和录音转写，修一个关键关系，延迟后换同结构不同数据。识图或转写错单列为工具错误，避免算到学习缺口。

比较无AI基线、辅助版、延迟独立版。只有成品提高不能证明人已掌握；AI赞许和模拟流畅不等于真实沟通验证。来源：[用AI学英语](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/threads/part-1/7-ai.md)。

## 9. 求职英语与远程岗位

从岗位提取申请、招聘筛选、项目说明、技术追问、行为问题、异步文档和会议修复。语言地图写岗位事实、所需动作和已有证据，找出专业能力尚未通过英语到达的位置。

基线含短介绍、项目说明、陌生追问、异步更新与澄清。内容缺口先重构经历；检索缺口练限时词块；听力缺口练问题关系；组织缺口练结论先行；互动缺口练修复；准确缺口只修改变意思的错误。

少量真实故事各留场景、任务、责任、取舍、结果代价、复盘。STAR帮助组织，不制造胜利。回答先结论，再支点、事实例子、边界，最后交还对话。

远程还看时区安排、会后补充、状态风险、take-home范围测试和交接。AI可模拟角色与新问法，不能造经历、数据或在禁止外部帮助的流程里隐蔽代答。

14天从岗位基线进入地图、故事、长短项目说明、澄清、延迟复测、专项题、异步写作、模拟、小修复、换面试者和最终撤架。门槛看内容、任务、理解、表达、互动、迁移与边界。面试后据实际问题和观察复盘，拒绝不全部归因于英语。来源：[求职篇](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/threads/part-1/8-job-search-english.md)。

## 10. 共同训练逻辑与研究边界

各技能日程不同，均围绕首版、具体障碍、最小修复、实际输出、反馈、延迟撤架、条件变化和下一轮决定。词汇看调用，语法看关系，听力看意义重构，阅读看依据行动，口语看听者理解，写作看署名交付。

原文引用检索与间隔练习、二语教学、词汇覆盖、听力策略、阅读、发音与反馈研究。结论依赖原样本和测量，14天与12周不是速成保证。全部入口见[资源索引](../sources/resources.md)。
