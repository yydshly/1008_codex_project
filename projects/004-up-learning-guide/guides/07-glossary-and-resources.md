# 术语、十组词表、引用资源与阅读路线

[返回概览](../README.md) · [逐页摘要](../sources/coverage.md) · [全部引用资源](../sources/resources.md)

这一页是前六篇的定位入口。术语说明按本研究改写，不把上游方法语言当成统一学术量表。每个词都应连接一个动作、样本或决定。

## 一、问题、证据与学习术语

| 术语 | 实际含义与使用判断 |
| --- | --- |
| 真实问题、场景 | 指定谁在何时何地需要完成什么；“提升自己”还不能直接练习 |
| 完成标准、主问题 | 用可观察结果验收；一周集中回答一个主要问题 |
| 基线、首版条件 | 工具介入前的原始样本，同时记材料、用时、帮助和限制 |
| 事实、解释、假设 | 来源或观察、对它的理解、尚待检验的判断，分别记录 |
| 推断边界 | 写清原文明示、证据支持与自己补出的部分 |
| 叙事压缩、回望偏差 | 简化故事可能删去偶然与他人贡献；不能把后来知道的信息倒灌进当时 |
| 完整学习回路 | 定义任务、留首版、诊断、定向输入、主动产出、反馈写回状态 |
| 主动回忆、间隔练习 | 合上材料自己完成；分不同时间回来检验，而不是持续看答案 |
| 精听/精读、窄读 | 短材料核对细节；同主题多材料积累背景、术语和结构 |
| 平行材料、变式、迁移 | 用相近难度的新内容，或改变受众、条件，检查核心动作是否仍能完成 |
| 延迟保持、证据链 | 过几天撤掉提示再测；连接基线、即时、保持、迁移及下一步 |
| 容量模式、学习主体权 | 按身体、时间和责任选择行动版本；学习者参与目标、首版、反馈与质疑 |

展开：[学习系统](01-learning-system.md)、[长期行动](04-life-and-long-term.md)。

## 二、英语诊断术语

| 术语 | 对应的动作 |
| --- | --- |
| 未知项决策队列 | 对未知词选择放过、推断、速查、主动学习或专业核验 |
| 词汇八维 | 词形、声音、当前义项、搭配、语法、语域、概念边界与调用条件分开检查 |
| 接受性/产出性词汇 | 听读理解和无提示说写是不同表现，分别保存样本 |
| 形式—意义选择、语法对比卡 | 比较结构怎样改变时间、参与者、条件、范围、逻辑与确定性，写修改理由 |
| 首听基线、支架阶梯 | 先无字幕留样本，再局部重听、转写、补背景，最后关闭文字并复测 |
| 意义重构 | 用自己的话恢复主旨、关系、细节与行动，不要求逐字复刻原音 |
| 首读基线、主张地图 | 记录首读条件；将文本拆为背景、问题、主张、理由、证据、限制与行动 |
| 技术事实卡 | 版本、前置、输入、预期/实际输出、错误与下一测试放在一页 |
| 参考变体 | 选择稳定词典音频、拼写或发音参照以减少初期决策，不给其他变体排等级 |
| 可理解度、理解难度、听众复述 | 检查别人恢复了多少意思、花了多少努力，再定位声音与组织问题 |
| 互动修复 | 请求重复、确认范围、争取时间、说明未知、总结共识 |
| 事实与责任账本 | 写作中逐项登记数字、引语、经历、推断、来源、权限与责任人 |
| 反馈吸收、署名决定 | 说明哪些反馈采纳及理由；判断是否能为最终文本的事实与责任署名 |
| 岗位语言地图 | 从岗位流程提取招聘沟通、项目说明、技术追问和异步写作任务 |

展开：[英语训练](02-english.md)、[全部工作纸](05-templates.md)。

## 三、AI、作品与交付术语

| 术语 | 对应的动作 |
| --- | --- |
| 任务卡/简报 | 写清本次输入、动作、范围、验收和责任人 |
| 学习状态文件 | 会话外有版本的事实页；保存证据、错误、边界和下一任务 |
| 证据卡、读者回执 | 前者记录能力首版与复测；后者检查阅读方法是否进入行动 |
| 案例复盘 | 区分来源、事实、当时判断、结果、成本与迁移限制 |
| 作品、交付 | 别人能读、用或质疑的输出；在真实受众和约束下接受结果 |
| 评估集 | 包含正常、边界、缺失/冲突和脱敏历史样本的固定验收集合 |
| 人工门 | 发布或执行前由具名人员确认来源、事实、权限、质量、成本、工具授权与责任 |
| 速度债 | 即时生成快，却把核验、返工、沟通和事故成本推到后来 |
| 回滚 | 暂停、降级、切换或恢复已知可用版本 |
| RAG、工具调用、工作流 | 分别为检索上下文、操作外部能力和组织多步骤任务；均需输入/权限/失败检查 |

展开：[AI 与项目](03-ai-and-projects.md)、[工作纸](05-templates.md)。

## 四、生活与边界术语

| 术语 | 对应的动作 |
| --- | --- |
| 恢复、恢复模式 | 先保护安全、照料和行动能力；安全/降档/重建是生活记录语言 |
| 复工试载、支持协议 | 一次只增加时长、复杂度、责任或公开程度中的一项；明确支持和归还控制权 |
| 边界 | 写清发生某事时自己会如何保护自己、暂停或退出 |
| 最小秩序、最小可行一天 | 在现实容量里保留安全、小输出与下一入口 |
| 精力预算、回归动作 | 把时间、身体、注意和责任纳入计划；中断后用小动作返回 |
| 节律、最小合同、节律账本 | 不同容量仍能辨认的行动模式、坏日子的降档协议与每周事实记录 |
| 复利 | 今日的能力、信任、判断和恢复使明日犹豫与返工更少；不是保证指数增长 |
| 代价、可逆性、价值冲突 | 列出需要承担什么、能否撤回，以及不能兼得时的优先级 |
| 决定权 | 说明最终签字/拒绝权限来源、受影响的人及责任 |
| 推翻证据、停止门槛 | 提前写明什么事实会改变选择，什么信号触发暂停、停止或求助 |

展开：[生活与长期改变](04-life-and-long-term.md)。术语原文见[上游方法索引](https://github.com/byoungd/up/blob/35e2aa9ad3a076fe4e8405877cc560df2593838f/docs/reference/glossary.md)。

## 五、十组技术英语词表

上游词表是英文术语清单，没有逐词释义、发音教学或完整语言课程。它们帮助从真实编程和 AI 任务选词，不能用累计背词数证明项目能力。

| 词表 | 覆盖方向与使用场景 |
| --- | --- |
| Common | 抽象、架构、并发、缓存、性能、协议、可靠性等通用技术概念 |
| Go | Go 语言与运行时、并发及常见开发术语 |
| Java | Java 语言、类型、运行时与工程概念 |
| JavaScript | JavaScript 类型、异步、对象与语言行为 |
| PHP | PHP 语法、运行与 Web 开发相关词 |
| Python | Python 语言、容器、函数、运行与工具概念 |
| Swift | Swift 类型、语言机制与开发相关词 |
| Rust | Rust 类型、所有权、生命周期、错误及并发相关词 |
| Prompt | 验收、约束、上下文、指令、检索、格式、token 与工具调用 |
| VibeCoding | AI 辅助开发中的任务、上下文、测试、工具与交付词 |

所有词条、每组数量和固定来源见[完整词表附录](../sources/word-lists.md)。这份附录保留源词的拼写，不自行补写可能过时或脱离具体技术版本的定义。

选词时从当前任务出发：查原始技术文档中的定义和版本，用词汇八维核验，保存听读识别与无提示说写例子，然后在自己的代码解释、需求或故障报告中调用。

## 六、引用资源如何使用

[资源索引](../sources/resources.md)保留中文导航正文中的去重 Markdown 外链及引用位置，机器数据见[resources.json](../sources/resources.json)。索引覆盖研究论文、官方文档、教学与练习入口、作者关联项目及历史资源；没有把它们全部包装为推荐清单。

| 来源类型 | 适合核对什么 | 阅读时保留的限制 |
| --- | --- | --- |
| 学习、检索、反馈与 AI 研究 | 方法依据、实验设计、平均结果、条件与限制 | 单次研究不等于对所有人保证，实验任务未必等于真实岗位 |
| CEFR 与语言学习材料 | 能力描述、语境、词典、语料、练习与发音参照 | 总体等级不能代替技能样本与工作任务 |
| AI 模型、工具与协议官方材料 | 实际版本、API/工具范围、上下文、权限、留存与评测 | 价格、功能和接口会变，使用前回到当前版本 |
| 项目、创业与案例 | 过去行为、流程、商业主张和公开结果 | 公开故事可能经过叙事压缩，关联入口存在利益语境 |
| 作者关联与历史链接 | 内容背景和作者当时的实践 | 不计为 Up 软件能力，不推定仍在维护或服务可用 |

本研究核对的是固定提交确实引用了哪些链接，没有逐一访问、审查或更新全部外站。上游媒体 HTML 引用与第三方权属另见 ATTRIBUTIONS；普通 Markdown 外链扫描不能替代素材许可检查。

## 七、按实际问题选阅读路线

| 当前问题 | 最短可执行路线 | 第一个可检查结果 |
| --- | --- | --- |
| 想了解库是什么 | 本项目概览 → 网站实现 → 完整目录 | 分清方法、内容、模板与代码能力 |
| 英语没有明确目标 | 学习方法 → CEFR/诊断 → 一项技能 | 四种首版样本与一个高影响障碍 |
| 技术英语读不懂 | 阅读 → 当前语言词表 → 阅读证据卡 | 一张技术事实卡和实际输入/输出 |
| 英文面试或远程协作 | 岗位地图 → 口语/写作 → 求职卡 | 无稿故事、陌生追问与异步消息样本 |
| AI 总给答案，人没有学会 | AI 学习 → 学习记录 → 证据链 | 关闭 AI 的独立版及延迟复测 |
| 会话很长，换会话就断 | 工具箱演示 → 学习状态 → 任务简报 | 有版本状态文件和一次正确交接 |
| 想做 AI 产品 | 客户发现 → 人工基线 → 任务简报 → 工作流/评测 | 一个真实需求试点与失败样本 |
| 想验证商业性 | 客户发现 → 创业实验 → 可持续小生意 | 过去行为证据、付费边界与完整工时 |
| 经常中断计划 | 容量/恢复 → 持续行动 → 节律/周复盘 | 一个能完成的回归动作与下一入口 |
| 准备长期投入 | 第一周 → 九十日总表 → 作品 → 周期后 | 基线、阶段门与结束决定 |
| 帮助孩子学习 | 家庭学习 → 共同协议 → 十四天复查 | 孩子自己的首版和双方确认的支持 |

路线是本研究对上游入口的归纳。若目标、容量或风险变化，就缩小任务或换路线；资料的价值最终由自己的动作与证据判断。
