## 文字版阅读顺序

1. **核心方向**：用真实任务学习，用证据判断成长；把学习转化为独立能力，让行动服务真实生活。
2. **能力范围**：英语能力；AI与真实项目；生活与长期成长。学习状态、任务简报、证据链与每周复盘为三类任务提供共同工具。
3. **行动闭环**：定义任务 → 保存独立首版 → 定向练习 → 核验并采用反馈 → 延迟复测与新场景迁移 → 更新状态，再决定继续、调整或恢复。
4. **价值观**：真实、诚实、主体性、可持续、负责。分别提醒自己用作品检验、分清事实与假设、保留自己的判断、尊重现实容量、守住隐私与责任边界。
5. **行动入口**：我在解决什么？证据在哪里？下一步能小到什么程度？

这里的“保存首版”强调保存自己尝试的过程；“复测迁移”强调撤去帮助后的独立表现。学习方法需由读者实施，图中内容不表示程序自动提供教学、云端记录或认证。
