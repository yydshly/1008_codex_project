# 暴风港 · 能源运输

玩家幻想：驾驶一艘轻型救援气垫艇，在风暴封港前回收六枚应急能源。

主行为是移动与运输；次行为是带热量代价的加速，以及九秒冷却的短程 EMP。每次最多携带两枚，返航交付会修复一格艇体，六枚全部交付获胜。150 秒倒计时或艇体归零失败，可立即重开。

最初两枚位于西侧，先学习拾取、装载和返航；中段需要绕中央平台去北侧；最后远端航线结合巡逻机与热量管理。好玩家读航线、合适时机放 EMP、带满货返航，并用交付恢复艇体。

美术为原创程序化工业港口：深蓝海水、橙色艇体、青绿能源、珊瑚红巡逻机、黄色起重机与磨损钢板。实体按轮廓、材质、状态细节构建。目标是可试玩的具体制作实验，不宣称商业 3A 或量化技能增益。桌面与手机布局默认支持；不调用外部付费素材生成。
