# 竹影问剑：第二版画卷界面

## 本次目标与依据

用户认为第一版简单，水墨风格不够鲜明。本轮先查看真实基线 `assets/ink-active.png` 与 `assets/ink-mobile.png`：原版已有黑白竹林，但直线状态条、宋体标题与方框按钮仍缺乏武侠画卷的笔触。本轮重新读取固定上游提交 `8286774b22a2566bf894dbc825825c16921866af` 的 `threejs-game-ui-designer/SKILL.md` 和 `references/ui-patterns.md`，按其要求将 UI 的材质、字体、颜色和状态反馈与场景统一。

## 改动

- 使用古绢纸 `#e8dfcc`、干笔浓墨 `#101610`、朱砂 `#982b20` 与少量苔绿 `#555e4b`。标题、人物名、章题和动作按钮优先使用本机 `KaiTi` / `STKaiti`，再回退到可读的中文衬线字体；没有外部字体下载或 CDN。
- 保留真实五格生命与气息、敌人生命、余时和轮次。状态条改为原创 SVG 笔痕遮罩，生命失去后留下淡墨，轮次以三枚小篆印显示真实已过阵数。干笔遮罩为本轮手写矢量图形，没有引入上游图片。
- 菜单采用楷体大标题、竖排短诗、朱砂篆印和墨刷主按钮。阅读区仅在画面左侧施以局部浅纸洗色，没有整屏模糊；右侧山水和角色保持可见。手机菜单仍可滚动，文字与主动作有稳定间距。
- 真实交锋状态在画面右缘加入竖题“竹影问剑”和当前对手 / 阵数，暂停、胜败和卷首自动隐藏。题款不进入中部交锋区域；手机缩小题款并隐藏较长对手竖题，矮屏横向布局直接隐藏题款。
- 斩 / 御 / 闪按钮用稍有倾斜的双层墨边与楷体字，成功反击时由 `counterReady` 驱动朱砂攻击按钮和“破绽已开”提示。没有新增战斗规则或假计分动画。

## 保留的交互约束

全部原有 ID、键盘映射、菜单状态、焦点循环、开始 / 恢复后的画布焦点、按钮语义和返回链接保持兼容。输入、战斗和 Game 未改动；UI 仍只读 `UiFrame` 并发送 `UiIntent`。

暂停按钮 46 × 46 CSS px；方向按钮通常 48 × 52、窄屏 44 × 52；动作按钮通常 56 × 66、窄屏 51 × 66；主按钮至少 51 px 高，设置和返回入口至少 44 px 高。安全区域仍使用 `env(safe-area-inset-*)`，减少动态设置保持有效。笔痕只绘制在按钮伪元素上，不裁切真实按钮点击区域。

## 验证与边界

本轮修改仅包含 `index.html`、`src/styles.css`、`src/ui/InkUI.ts` 和本记录。`InkUI.ts` 独立严格 TypeScript 检查与改动空白检查通过，本机确认有 `C:/Windows/Fonts/simkai.ttf` 楷体文件。整项目 TypeScript 检查时场景模块正在主流程更新，提示暂时缺少 `src/assets/InkWorld`；合并后整包构建由主流程完成。

最终与新生成背景 / 角色合并后的真实桌面、手机、菜单和胜败截图由主流程检查。实际字体由设备决定，其他系统会使用本地回退字体。本记录不预先把运行验证或手机硬件验证写成通过。
