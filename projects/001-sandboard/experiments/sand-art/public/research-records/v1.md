## 2026-10-10 · v35 灯台留白方向验证

用户指出 v34 仍很差，尤其失去沙画感觉。重新查看 Ilana Yahav 的官方作品与背光沙台说明，观察厚沙遮光、留白、粗糙边缘与连续手法；不复制其素材或动作。独立增加 `keepsake/sandlight/`，从整杯灰色细碎填面改为先撒厚沙、掌缘推开杯身灯光、指腹收杯口与热气、留下边缘沙脊和少量余粒。首轮留白过直且杯底长弧，热气未显出；第二轮调整杯身曲线、杯底位置、杯上薄沙与收沙残留。

环境为 Windows、TypeScript 6.0.2、Vite 8.3.3、Three.js 0.186.1，沿用既有 AI 雨窗示例和虚构故事。运行四个相关测试文件共 22 项通过，`npm.cmd run build` 输出十一入口，根 `npm.cmd run check` 通过。实际产品按钮导出 VP8 / 1080P / 45.61 秒短片，1353 帧全解码，赠礼 HTML 嵌入的视频与下载逐字节一致。v34 源码、路由与资料共 29 文件 SHA-256 不变。详见 [实际证据](assets/keepsake-sandlight-v35/README.md)。

观察：新的遮光与留白比灰色素描更能表达沙层，但轮廓仍规整、空中粒子和接触为近似，尚不足以被称为真人沙画或商业纪念片。宽掌一次收出杯身的过程仍需要进一步减少模板感；未验证任意真实物件照片与手机性能。质量验证与流程验证分开记录，不能用构建、导出或质量守恒测试替代艺术效果判断。

## 2026-10-09 · v17 接触小样与细笔落定

修正细笔撒沙后自动揉开、收沙手势被当作掌面、手部视频独立循环、固定接触点随素材漂移和刷新丢失素材。新增按手法独立的实拍片段库与逐笔寻帧、多帧接触点插值、动作截取及 IndexedDB 保存。实际浏览器查出逐帧标定的解码竞态后加入等待提示，阻止误标旧帧。

新增 15 秒正常速度真人手部与数字沙台接触小样；原片来自 КРТ 2019 节目，CC BY 3.0，节选 135–136.4 秒并抠除背景。修正手臂被裁断悬浮和释放点投影偏差；沙粒实际下落并沉积。完整新雨窗动作重新校验，共 2042 笔、1337 笔细节只落定；旧动作规则保持。实际输出、署名与验证边界见 [v17 素材记录](assets/material-realism-v17/README.md)。

当前背光手部较暗，抠像、连续真人动作、背景斑块和照片碎笔尚需优化，未达到不可分辨生成痕迹的目标。

## 2026-10-09 · v16 手与沙的质感试镜

用户将首要目标设为真实手部与沙的质感。新增独立 WebGL 2 颗粒呈现，以两倍材料网格分辨率描绘粒形、稀疏间隙和厚度梯度；材料状态和实际动作保持。可在同一帧切换原影调并保存所选外观。新增实拍手部 MP4 / WebM 色键、接触点标定、试镜 PNG；视频只在页面会话内使用。没有新 AI 手部素材。

真实参考来自有 CC BY 3.0 许可和原始来源的 КРТ 2019 沙画节目，节选 55–71 秒、无声转码；明确归入对照，未冒充本程序输出。实际颗粒成品、来源许可、哈希和有限验收见 [v16 素材记录](assets/material-realism-v16/README.md)。画质仍受当前照片沙层轮廓影响，手部短片还不能和任意供沙姿态同步，未达到难以分辨生成痕迹的目标。

验证命令：`npm.cmd run build`、`npm.cmd test -- --maxWorkers=1`、根 `npm.cmd run index:build` / `npm.cmd run check`。首次默认并发有两个未改动的旧演出测试超过 5 秒；单进程 231 项通过、1 项显式离线取证跳过，没有修改断言或材料算法。浏览器验证范围以素材记录为准，未开展盲测或重新测试原版硬件 GPU。

## 2026-10-08 · 沙画方向与版本约定

用户确认的方向：

1. 原版能力作为固定效果展示版本保留。
2. 基于该版本，在独立实验版本中逐步增加更多效果。
3. 以沙画作为主要创作方向，沙面绘画与灯箱沙画都保留，作为不同模式。

此阶段 `web/` 保持已有演示与固定上游研究基线。扩展计划属于同一 `001` 子项目，独立维护实验源码与入口；这一阶段只更新说明和首页研究摘要，未实现新模式，也没有修改现有网页或模拟。后续实现记录见下节。

初步架构判断：现有 `SAND.depth = 0.032`、`floor = 0.003`，对应 32 mm 厚沙床与 3 mm 底限；输入、求解、相机与重置依赖全局配置。灯箱沙画需要允许无沙的透光区域，另设薄沙尺度和光学表现，不能只把当前画面改成深浅色。持续撒沙还需要按时间产生沙量输入，不能只复用现有“移动时才产生接触”的约定。

拟议的共同创作操作为撒沙、推沙和刮线，但每种操作应明确沙量的来源与去向：撒沙来自外部沙料，推沙在画布内转移，移除沙子则进入收集区或清场出口。沙面模式重点表现几何，灯箱模式重点表现覆盖与透光；这是待实验验证的设计方案。

首个里程碑建议在两个模式中完成「撒沙 → 推沙 / 刮线 → 导出图片」，保留原版展示作为视觉和交互对照。先验证创作行为与材料表现，再研究撤销、可编辑存档、演示回放和更多粒子效果。

## 2026-10-08 · 独立沙画工作室与效果实验

目的：落实「原版展示保留、扩展独立研究、沙画作为主方向」的版本约定，让两个模式都能完成绘画、撤销、保存与导出，同时尝试光照、湿沙和风。

### 环境与改动范围

实验位于 [experiments/sand-art/](experiments/sand-art/README.md)，不修改 `web/` 基线源码。独立使用 TypeScript、Vite、Vitest 和 WebGPU/WGSL；Node.js 要求 `>=22.12`，实际依赖版本锁定于 [package-lock.json](experiments/sand-art/package-lock.json)。硬件 GPU 测试通过 `webgpu` 运行真实 WGSL，与常规轨迹测试分开执行。

实现参考 Sandboard Commit `489cb01e81b11ba575887f7c76760498eb41aaa8` 的高度场、八邻域输运和 GPU 双缓冲思路；实验着色器中保留来源说明，GPL-3.0-only 原许可证保留于 [LICENSE](experiments/sand-art/LICENSE)。新增求解器、表面/透光渲染、五种工具、中文创作界面、历史、IndexedDB 存储与 GPU 离屏导出，实验不包含原版飞沙、水面和音频流程。

### 输入与实现

| 范围 | 输入 / 处理 | 实现结果 |
| --- | --- | --- |
| 两种模式 | 默认灯箱，顶栏切换至沙面 | 各自维护沙床、设置与历史，切换不会覆盖另一幅作品 |
| 工具 | 撒沙、推沙、刮线、五齿沙耙、心形印章，`1–5` 切换 | 移动轨迹按画布距离细分；撒沙和印章支持持续静止按压 |
| 沙量 | `512 × 384` 网格，厚度允许归零 | 厚度为无量纲实验值，不对应真实毫米；沙面初始较厚、灯箱初始较薄 |
| 模拟 | `1/120` 秒固定步长，每帧最多 4 次追赶 | 接触场 → 八邻域通量 → 汇总更新，三次计算派发；每个追赶步骤使用独立 uniform 缓冲 |

### 沙画输入与沙量

工具新增「抹平」，`1–6` 对应撒沙、推沙、刮线、五齿沙耙、心形印章、抹平。短按撒沙可见，按住继续堆积；抹平降低接触区的稳定阈值，让局部高差松弛，不添加沙量或施压挖沟。

移动轨迹改为 GPU 扫过完整胶囊段，保留实际曲线采样，减少人为细分端点的重叠与点串。默认关闭自然流动，空闲时保留笔迹；开启「沙面自然流动」后无接触区域继续松弛。保持笔迹状态仍允许工具、撒沙和风生效，并保存在模式草稿的参数中。

最终实际采样校准进一步让刮线、沙耙近直线段共享起始锚点，静止接触保持同一胶囊；转角或回头时以真实上一采样为新起点，其他四工具行为保持不变。厚度参考改为读取胶囊中心线，避免边缘沙坝成为高压环。本机网页厚图刀笔已显示连续亮沟，改善此前十个孤立亮点与端帽珠圈；尾部接触驻留较短时仍渐收窄，不能宣称全线完美同宽。

求解器新增接收容量阶段。雕刻与抹平时，接触场生成一次，八邻域通量 → 变形接收容量 → 汇总更新执行 3 个局部子步，各使用 `dt / 3`，总计 10 个计算派发；仅撒沙或无工具时仍按一个时间步执行四阶段，撒沙和风的时间率不倍增。容量约束只用于工具变形堆出的沙脊；撒沙和风的独立守恒输运保留。沙量仍由 `512 × 384` 无量纲高度场表达，不是完整三维粒子体系。

最终厚底校准发现：绝对 `0.8` 的薄沙接收上限会让 `1.25` 的厚模板难以刮动。现在使用加载时固定的 `referenceBuffer` 为基底，按原始厚度给沙脊分配容量；默认薄底仍维持 `0.8` 附近约束，厚模板得到相应空间，工具持续运行不会逐步抬高基底。模板、图片、清场和草稿通过统一加载路径同时更新两个模拟缓冲和参考基底。

历史快照同时保存沙床和参考基底，恢复时同步写回两个模拟缓冲与基底；新增真实 GPU 历史回归验证模板撤销后的基底一致性。草稿仅保存沙床及参数，刷新后以载入沙床重建预算基底，不保存刷新前的预算参考或撤销栈；参数改动不纳入历史的边界保持不变。

### 沙画材质与作品起点

颗粒随机域改用 `u32` 整数散列，避免大坐标浮点散列精度丢失导致有方向的织物条带；颗粒在沙床坐标中保持一致，并按像素覆盖进行抗锯齿。沙面降低高度梯度与阴影的放大，减轻尖锐折纸感，清空后露出哑光画台。灯箱薄沙保留灰棕透光颗粒，堆叠厚沙逐渐形成连续暗部，避免把整层薄沙画成纯黑噪点。

撒沙按下时增加细粒落点与小阴影动画，它只反馈正在发生的厚度场加沙，不是参与质量交接的三维飞沙粒子。导出的作品隐藏光标，因此不包含该按压动画。

「山月沙画」「沙纹园」「空白画台」直接生成可编辑厚度场；载入时关闭风和自然流动，支持继续绘画与撤销。山月图案由程序绘制后转换明暗；沙纹园由程序高度函数生成，没有真实石块障碍。

图片转沙画在本机读取 PNG、JPEG、WebP（小于 20 MB），保持比例适配网格，将灰度明暗转换为厚度，不上传文件。它不是照片色彩复制或三维重建。新增画台全屏和画台内六工具、退出按钮；宽度不超过 680 像素时隐藏下方重复工具栏，切换工具无需离开画布。全屏支持继续绘画、键盘切换工具以及退出返回参数区。

### 撤销、重做与本地作品

每个模式的 GPU 历史同时快照沙床状态、工具参考基底和工作室元数据，支持撤销/重做。元数据包括画笔与效果设置、参考图 Blob/像素/名称、转换参数、作品名与本地作品编号；恢复时同步更新两个模拟缓冲和参考缓冲，并重建活动参考图 URL。替换活动参考后释放旧 URL，历史不依赖已经释放的 URL。撤销与重做合计最多 10 步，新的修改清空重做分支；`Ctrl / ⌘ + Z` 撤销，`Ctrl / ⌘ + Shift + Z` 或 `Ctrl / ⌘ + Y` 重做。

自动草稿与命名作品集使用不同的 IndexedDB 存储区。完成笔画立即启动异步草稿保存；参数编辑采用 900 毫秒防抖，在更改完成时也立即保存。界面显示待保存、保存中、成功或失败，两模式分别恢复最近成功写入的草稿。草稿包含沙床、工具参考基底、设置、参考图、转换参数、作品名和所属作品编号，不包含历史栈。旧草稿没有参考基底时，从载入的沙床重建。

输入作品名后，「保存作品」创建或更新当前命名作品；「另存副本」创建新作品，「打开作品集」通过缩略图继续创作，「新建」重置为新的画台。自动草稿不会直接覆盖作品集快照。存储仍限同一浏览器与站点来源，`127.0.0.1` / `localhost`、不同端口分别保存；没有云同步。页面退出尝试先完成保存，但关闭浏览器进程瞬间的异步 GPU 读回与 IndexedDB IO 不保证完成，应以成功状态判断最近一次保存。

### 工程文件与成品图片

`.sandart.json` 是当前模式的可编辑工程，保留沙床、工具参考基底、设置、参考原图、转换参数及作品名，导入后可继续绘画。导出不携带本地作品编号，导入不会直接覆盖另一个浏览器的命名作品；文件不包含撤销/重做栈或操作回放。工程导入上限 60 MB，校验版本、矩形网格尺寸、缓冲区长度、沙量与参数范围、参考图片格式；失败时保留原作品，成功载入可撤销。

## 2026-10-08 · v4 创作过程的录制、回放与视频

在 v3 工作室上补齐过程展示。录制固定当前模式，保存起始沙床、工具参考基底、实际 `1/120` 秒计算步骤和外观；相同连续计算步采用重复次数压缩，包含掌形松手后 10 个尾步。清场、示范、应用图片、撤销/重做按操作边界读回快照，异步完成先后不会改变记录顺序。限制为 21600 步（3 分钟模拟时间）与包含起点在内的 8 个沙床快照，达到上限自动结束。

最新录制保存在独立 IndexedDB 数据库，刷新可恢复；`.sandrecord.json` 支持携带起点、计算事件与精确沙床快照，不包含参考原图或本地作品编号。文件上限 128 MiB，校验版本、同模式、所有接触参数、计算步与总步数；有效文件即使本地存储写入失败，仍可在本次页面回放。非法版本不替换此前有效录制。

回放使用独立求解器与渲染器，最多 4 个 GPU 检查点，每批最多 4 步独立提交。支持 0.5 / 1 / 2 / 4 倍速、暂停和时间轴定位。旧推进或跳转以 operation token 与求解器 generation 取消，不能覆盖新跳转、退出或重播状态。浏览器验证中发现 GPU 推进期间的暂停请求曾被 busy 判断丢弃，已经修正；暂停停止后续推进，当前批次完成即可停住。连续键盘跳转保持 range 焦点并采用最新目标，点击不改变进度也会释放拖动标记。

真实下载的第一段录制共 62 个计算步（约 0.517 秒），其中掌形 19 步，最后 10 个尾步完整。另在硬件 GPU 读取此文件进行回放，再与晚导出的工程比较：196608 个高度值位模式全部一致，参考基底 3 MB 字节全部一致；活动量和速度因原画额外空步衰减而不同。这段操作改变 35013 个网格高度（约 17.81%）。退出回放后的工程高度差异为 0，参考基底和作品名保留。

第二段真实录制包含掌形、撤销/重做与日落光照切换，刷新恢复为 19.3 秒。半速播放在 5.3 秒暂停后位置保持，四倍速、起点/末尾定位以及 Home、PageUp、PageUp 连续跳至 3.8 秒通过；焦点仍在时间轴。录制导入不改变当前作品名，版本 99 被拒绝并保留已有录制。画台原作仍可编辑。

WebM 导出使用另一份独立回放和 1024 × 768 WebGPU 画布，目标 30 fps、1 倍实际过程、无声音、无参考/网格/工具光标。浏览器 MediaRecorder 优先 VP9，其次 VP8 和 WebM；导出可取消，资源在成功、失败、取消路径统一清理。实际取消后额外视频画布数量为 0，创作控件恢复。完整导出 [真实 WebM](assets/art-replay-v4.webm)，ffprobe 检查为 VP9、1024 × 768、19.4178 秒，ffmpeg 解码 580 帧并查看首尾，沙床变化清楚。

原生 MediaRecorder 输出缺少总时长；新增最小 EBML 模块，使用 start 到 stop 的实际时钟（包括最后画面停留）补充 Duration。原位替换已有值/预留 Void 时不改变索引位置；没有索引或校验结构时可以插入并更新有界 Info、Segment 长度；无法安全修改则原 Blob 无损返回并提示。真实样本只增加 11 字节，全部 14 个编码包的时间戳、大小、SHA-256 和解码帧 MD5 不变。没有生成 Cues 或宣称所有播放器都能拖动。

## 2026-10-08 · v6 自然撒沙与山月演示

针对上一轮撒沙落区过于均匀、缺少创作过程展示的反馈，本轮只扩展独立沙画实验。保留 v5 的抓沙、有限手中预算、三种释放方式、下落沉积与个人录制能力，增加自然分布和完整山月演示；原版展示、上游求解器与许可文件未变。

### 发射分布、流量与沉积

新输入以 `pour.natural: true` 选择自然模型。连续释放来自相关漂移的多股指缝源，中心和几处局部聚团较密，边缘较稀疏并有少量远散颗粒；整体有椭圆和方向偏置。一把撒开按确定性随机状态改变每次的方向、宽窄与各股比例，形成不同的整把形态。粒子包质量不相等，发射前按本步实际总量归一，最后一个包接收剩余量，保证不增加或遗漏预算。

`naturalFlowAt(模拟时间, 手势, x, y)` 使用平滑相关噪声与脉冲给出 `0–2` 的实际流量倍率，强弱连续变化，不按帧重抽白噪声。工作室先把这一倍率写入接触，再使用相同倍率分配手中余沙；物理发射只使用记录下来的倍率，不在重放时重新估计。单次一把撒开的倍率固定为 1，仍由 `burst × strength × pressure` 和手中剩余量决定总量。

自然粒子落地时，在沙床坐标中的最多四个邻格做紧凑双线性沉积，减轻单格尖点而不抹成均匀大圆刷。边缘位置先收进封闭画台，粒子池上限仍是 8192，满池合并包质量。CPU 飞沙中的质量和累计沉积量共同对应实际发射量；GPU 每个 slot 仍有独立落点缓冲，混合雕刻的三个局部子步不会重复加沙。

### 旧录制与确定性

缺少 `natural` 的传统撒沙接触保持 v5 的随机调用、轨迹、不等步长处理和单格落点算法；缺少完整 `pour` 配置的早期录制保持原即时沉积。自然模型新增累计模拟时间 `elapsedTime`，每个有效步骤更新，清空时归零，检查点与粒子、随机源一同保存和恢复。新录制写入实际 `flow`，从中途飞沙检查点回跳后仍可精确重放。

上一轮真实网页下载的 34 秒、4080 步 v5 录制已在新实现上再次运行真实硬件 GPU：全部 196608 个高度位与原导出工程一致，3145728 字节工具参考基底一致。净新增仍为 3499.999650090933，距 3500 手中预算差 −0.000349909067；末态无待落沙，GPU 错误为零。此项是旧文件兼容复核，不代表 v6 界面验收。临时审计测试已移出项目常规测试目录，保留在指定本机临时审查目录。
