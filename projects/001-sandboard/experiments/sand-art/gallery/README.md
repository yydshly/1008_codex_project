# 我的作品集 · 统一入口

## 历史作品与成画过程

`#history` 新增34项历史作品与效果，覆盖v1–v36。目录复用研究档案的27项记录，并补入苍柳、石桥、原归舟手势、另外两幅AI目标及其实际参考还原作品。首屏优先展示遗漏的可接管作品和早期雨窗效果，默认显示六项，可展开全部，并按方向、呈现类型、名称和版本查找。它们不计入私人收藏，也不修改原作品库。

每件卡片明确标注实际数字沙层、实际效果记录、AI参考目标、照片影调预览、手部合成试验或平台界面。三张AI美术目标没有可接管入口；照片与无手照片记录说明AI虚构输入。十一段保存录像在点击后才加载，关闭弹窗或离开页面后停止并释放媒体；其中v29、v30是局部片段，不冒充完整演出。

七件可接管作品（柳、桥、侧脸、原归舟及三幅参考还原）分别通过 `atelier/#score=<名称>&view=process|finished` 或 `atelier/#reference=0|1|2&view=process|finished` 打开正确编排。成品入口重建原动作后的实际沙层，再由用户点击「接过这幅画」操作；只进入演示不会覆盖手动草稿。原 `#pause`、作品选择、参考还原、导入导出和恢复草稿保持可用。其他历史记录进入保留平台，保存图与录像对应当时版本，平台内可能包含后续模式。

本轮补齐作品组织与入口，没有修改粒子、材料、手部、成画动作谱或渲染算法；没有解决真实沙画质感与打印感。统一收藏仍只读取原手绘、照片两个命名作品库，创作台、舞台和纪念短片的独立草稿未迁入此列表；云同步和统一备份仍待实现。

验证：`npm.cmd test -- tests/historical-gallery.test.ts tests/handdraw-examples.test.ts tests/unified-gallery.test.ts tests/product-storage.test.ts --maxWorkers=2`；独立测试源4274验证柳树、石桥、参考还原的定位、接管与原草稿恢复。浏览器证据与范围见 [历史作品入口验证](../../../assets/historical-gallery/README.md)。

## 手绘示例，点击就能试画

`#examples` 展示九幅实际画台效果：早期的沙纹园和山月沙画，加上沙耙、撒沙、推沙、刮线、心形印章、抹平与掌形工具小样。可按工具筛选；图片和卡片按钮都进入原工作室 `art/#example=<名称>`，自动载入沙层、模式和工具，并滚动到画台。

两个原构图直接使用原 `createComposition`；七工具小样通过原 WebGPU 求解器执行真实工具输入，沙层可继续绘画，没有把缩略图贴到画台。图片是实际画布截图；完整原导出也保留在 [素材目录](../../../assets/handdraw-examples/README.md)。

首次打开前保存原草稿。试画使用独立 `sandboard-handdraw-examples` IndexedDB，按示例分别暂存；「返回原草稿」恢复原沙层、参考图、标题及设置。「恢复示例原貌」恢复并立即提交示例暂存；已经保存的个人副本继续保留。点击「保存作品」沿用原手绘收藏功能，出现在下方「我的收藏」。示例不占个人作品数量，不改变照片库或原手绘库的版本。

九幅示例均可从全新浏览器查看；原画台操作继续需要 WebGPU。当前为数字工具示例，没有新增真人手部、AI 图像或大师作品复现。

本地访问：[统一作品集](http://127.0.0.1:4174/1008_codex_project/001-sandboard/art/gallery/)。首页与所有页面顶部导航都可进入。

作品集读取当前浏览器、同一来源下已保存的手绘与照片作品，显示实际保存的缩略图；支持全部／手绘／照片筛选、名称与故事搜索、更新日期排序和大图预览。手绘作品的“继续创作”恢复原沙层、模式、工具与参考图；照片作品恢复原照、沙层、风格、故事及已保存的演出，仍可修画、展映和导出。

手绘存储 `sandboard-art-experiment` 和照片存储 `sandboard-photo-memory` 保持原样。读取不迁移、不复制或重写收藏；列表仅持有缩略图与元信息，打开作品时才读取完整工程。不同库中的同名编号使用类型前缀区分。单库读取失败会提示重试，并保留另一类作品；早期没有缩略图的手绘作品显示明确占位与原画台入口。自动草稿仍回到原画台查看。

直达地址：

- 全部作品：`art/gallery/`
- 手绘收藏：`art/gallery/#type=hand`
- 照片收藏：`art/gallery/#type=photo`
- 指定手绘作品：`art/#work=<编号>`
- 指定照片修画：`art/memories/#edit=<编号>`
- 指定照片展映：`art/memories/#work=<编号>`

工作室 `art/#gallery` 的原弹窗、照片平台 `art/memories/#gallery` 的原列表继续保留。统一作品集不是账号云端同步；`localhost`、`127.0.0.1` 或不同端口属于不同浏览器来源，作品可用原平台工程导出备份。

首页七个工具分别直达原沙台：沙耙、推沙、刮线、印章、抹平和掌形默认沙面；撒沙默认灯箱。进入时恢复相应草稿并选中工具，不自动清空画面。用户仍可在原画台切换两种模式和所有工具。

验证：`npm.cmd test -- tests/unified-gallery.test.ts tests/storage.test.ts tests/input.test.ts tests/product-storage.test.ts --maxWorkers=2`，随后构建平台并运行 `node scripts/validate-platform.mjs` 与 `node scripts/validate-research.mjs --built`。实际网页证据见 [统一作品集验证](../../../assets/unified-gallery/README.md)。
