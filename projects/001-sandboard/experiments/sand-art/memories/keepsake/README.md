# 光阴沙画 · 纪念短片（v32）

产品入口：`/1008_codex_project/001-sandboard/art/memories/keepsake/`。这是现有实验中的第八个独立 HTML 入口，不替换茶杯 v31、照片 v30、手部试验或原版。

首版面向个人纪念与赠礼，限定杯子类纪念物。照片需要由用户确认杯身范围、下沿收口、杯口弧度、杯把和托碟。程序按确认的宽高比例生成实际动作，暂不识别物体类别，不复刻花纹、文字或背景，也不承诺任意纪念物或复杂人像的还原。

## 可使用的流程

1. 上传 JPG、PNG、WebP、AVIF（20 MB 以下），填写作品名字、赠送对象、240 字以内的故事和结尾赠言。选择暖纸或深夜包装氛围。
2. 在照片上拖框确定杯身；也可用数值滑块操作。杯把可以在左、右或省略，托碟可选。
3. 确认构图，生成 45 秒演出：4 秒片头、约 33 秒主动作、约 2 秒落定和 6 秒结尾。支持完整播放、暂停、时间轴、单笔观察、慢放与收沙前后对照。
4. 制作 WebM 短片，下载视频、实际成品 PNG 海报、内嵌视频的离线赠礼 HTML，或备份包含照片、故事和构图的 `.sandmemory.json` 工程。工程入口在所有步骤都可访问。

示例复用本项目 v12 的 AI 生成雨窗照片，示范故事为虚构内容；示例按钮明确标注来源。上传文件测试同样使用这一生成照片，仅用于验证上传通道，不能替代真实用户照片的美术验收。

## 照片如何影响沙画

`keepsake-model.ts` 根据框选像素宽高计算杯身的几何比例，并结合下沿宽度、杯口、杯把与托碟调整路径。照片位置用于定位参考物；沙画把主体重新居中安排在灯箱里。宽高被约束在适合当前模板的范围内，极端比例会被概括。

动作数量为 6 至 9 个，来自已有 v31 语义手法的独立变形。供沙预算按杯身面积调整；杯口收沙宽度受当前杯口高度限制，避免扁口杯被宽工具擦掉杯沿。没有扫描线、逐像素点阵动作、最终照片贴图或结束换图。照片像素不进入 `KeepsakeStudy` 和 `PhotoSurface`。这是人工确认构图后的杯子模板适配，不是自动照片理解。

`keepsake-material.ts` 使用独立随机种子与沙层。撒沙为连续的空中供料，带供料起落、轻微摆动与聚团。收沙复用 v31 的守恒局部推拢和坡度松落：移动时保留沙量，先形成前缘沙堆，停驻 0.25 秒，然后在末端分次拾起。它仍是连续厚度与供料包近似，不是逐颗粒碰撞或实拍。

`keepsake-scene.ts` 仅读取实际材料，固定渲染 1440 × 960 沙台。产品视频的 sRGB 2D 包装画布为 1920 × 1080，叠加片头、故事字幕与赠言；这不等同于 1920 × 1080 的独立材料网格。观察镜头可切换，正式成片固定使用俯视灯箱。

## 数据、导出与边界

- 照片在浏览器内缩小至最长边 1600，保存为 JPEG；无需 API 密钥或后端。
- 照片、故事和构图自动保存到独立 IndexedDB `sandboard-keepsake-film`，不修改旧版作品集。
- 成片暂保留在当前页面内存中，刷新后需重新制作；下载的视频、赠礼网页和工程文件可独立保留。
- 原照片默认不进入赠礼网页。用户勾选后才附上；故事与赠言会进入网页。工程备份始终包含照片。
- 赠礼网页是内嵌视频的离线文件，不是已上线的公开分享链接。没有账号、支付、云同步或订单管理。
- 视频为 WebM，无音轨。录制要保持页面可见；切入后台会中止制作，草稿与上次成片保留。实际录制可能受设备性能影响而超过 45 秒，界面显示实际时长。
- 故事和赠言只作为文字输入，不自动推断人物情绪或编造用户经历。HTML 输出转义用户文字。
- 支持取消制作，已完成的成片不会因取消下一次录制而丢失。

## 验证

运行子项目 `npm.cmd run build`、`npm.cmd test -- --maxWorkers=2 --testTimeout=30000` 和根 `npm.cmd run check`。较高超时用于本机同时运行 WebGL 验证时的既有慢测试，不修改旧测试或放宽材料断言。

自动验证覆盖照片比例改变动作、左右杯把与无碟分支、工程非法输入、真实收沙守恒、片头空台、结尾不换图、重复演出一致、本机保存以及赠礼文字转义。实际浏览器与媒体证据记录在项目 `assets/keepsake-v32/`。

本机浏览器策略拒绝 `file:` 协议，因此没有直接打开下载的赠礼 HTML。已静态检查网页内嵌视频与下载视频字节一致、文字完整、原照默认排除；网页内实际离线播放仍需要用户在自己的浏览器打开文件核对，没有绕过此策略。
