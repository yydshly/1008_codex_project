# v33 杯子质感版

本机入口：`http://127.0.0.1:4174/1008_codex_project/001-sandboard/art/memories/keepsake/natural/`。`../` 仍是未修改的 v32 纪念短片。新版本继续使用照片＋故事、确认构图、观看过程、交付短片的四步流程。

这次改动集中于杯子模板：

- 材料网格从 768 × 512 提至 1152 × 768；沙台渲染从 1440 × 960 提至 1920 × 1280，交付仍为 1920 × 1080。
- 空中速度决定散布，落地采用紧致 3 × 3 核，不再把宽散沙摊成 7 × 7 灰团；每个时间步错开出生时间与高度，沙流在起收笔渐停，停供后仍有余粒落台。
- 杯身绕底铺沙之后，余沙向内侧铺开；仅两段连续宽幅曲线，没有逐行描点、目标灰度或成品覆盖。
- 推拢采用有方向的粗糙掌缘，质量沿小步移动；停驻约 0.4 秒后分次拾起，离台沙粒保留约 0.35–0.48 秒可见时间。拖痕留有少量细沙，局部过陡沙坡才会松落。
- 米制尺度的沙粒着色保留透光空隙、棱角、厚层吸光和沙脊；颗粒固定在沙台上，没有逐帧随机噪声。

`keepsake-natural-*` 为独立实现，底层复制并调整本仓库原创的 `stage/material.ts`；v32 源文件、素材和视频不变，保留清单在 `assets/keepsake-natural-v33/preserved-v32.json`。上游 Sandboard 来源、研究提交和许可沿用子项目说明，不新增第三方素材。示例仍为 v12 AI 生成的雨窗照片，故事为虚构示范；网页明确标注来源。

草稿保存到 `sandboard-keepsake-natural-film`。首次进入没有新草稿时，只读取并复制 v32 草稿；两版随后独立保存。v32 `.sandmemory.json` 可以在新入口打开，照片与故事相同，但重制会使用 v33 的材料和动作。

构建与测试在 `experiments/sand-art/` 执行：

```powershell
npm.cmd run build
npm.cmd test -- --maxWorkers=2 --testTimeout=30000
npm.cmd run preview -- --host 127.0.0.1 --port 4174 --strictPort --base /1008_codex_project/001-sandboard/art/
```

本轮是沙层与动作近似的改善，不是完整离散颗粒动力学或真人表演。首版仍限手动确认的杯子概括轮廓，不还原照片花纹、文字和背景。没有实拍质感保证；远景、细口处和厚沙仍可能带有程序模拟痕迹。WebM 无声成片、PNG、工程备份及赠礼打包沿用产品流程，没有新增配乐、MP4 或线上分享。
