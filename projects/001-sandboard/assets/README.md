# 图片与素材

保存 Sandboard 交互沙盘的真实截图、架构图和演示素材。本轮新增 v7 独立舞台《月下江南》的过程、成画截图与实际导出 PNG；既有 v1–v6 文件保留原版本、来源与许可说明。首页封面仍为原版展示，不以新增舞台替换。

- 项目 README 使用相对路径，例如 `assets/cover.png`。
- 首页封面在根 `projects.json` 中设置为 `projects/001-sandboard/assets/cover.png`。
- 同时填写 `coverAlt`（画面内容）、`coverCaption`（图注，可包括场景和版本）。
- 引用上游图片时记录来源和许可，生成的图应说明其描述的是哪个版本。
- 每张图应有实际对应的文件；尚无图片时保留封面字段为空。
