# 手绘沙台与作品集入口 · 2026-10-10

用户提醒早期可以用沙耙等工具直接画画的能力。工具仍在工作室，当前照片页面的作品集却只展示照片收藏，入口和命名不够清楚。本轮在照片创作与收藏页补上手绘沙台、沙耙和手绘作品集，首页也增加直达。

## 保留能力与改动

七种工具为撒沙、推沙、刮线、沙耙、印章、抹平、掌形。原沙面、灯箱、撤销、收藏、录制和导出都保留。本轮仅调整入口和显示名称，在工作室初始化后解析地址，复用原模式/工具按钮或打开原收藏；`#demo` 原演示入口继续保留。

- `art/#mode=surface&tool=rake`：恢复原沙面草稿，选中沙耙，可立即拖动绘画。
- `art/#gallery`：打开手绘作品集，可重开继续画。
- `art/memories/#gallery`：打开照片作品集，可切到手绘收藏。

不清空、合并或迁移作品库，不改变材料、渲染或输入采样。修改前 526 个源码/既有素材建立 SHA-256 清单；519 个逐字节保持，7 个变更为工作室入口、UI、照片入口/样式、首页、公共导航及页面描述。所有历史资产与实际算法源码保持，见 `preservation.json`。

## 实际验证

试画采用独立 `127.0.0.1:4274` 来源；没有在用户 4174 来源试画、保存或覆盖作品。用户已有未保存调整的照片标签页未刷新。

1. 从照片作品集点击“试试沙耙”，载入后实际为沙面模式与沙耙工具；用真实指针拖动画布，出现五齿沟槽和沙脊。
2. 七个原工具都实际点击切换，当前状态逐一选中；未宣称重做七种材料效果的完整回归。
3. 为测试手绘命名并保存，作品集中出现实际缩略图。通过“查看照片作品集”返回照片收藏，再经“手绘作品”重新打开原手绘收藏，点击“继续创作”恢复同一纹路和作品名称。
4. 390×844 窄屏照片入口无横向溢出，三个手绘链接均高 44 px；实际点击后进入已选沙耙的画布。结束恢复正常视口。
5. 本轮浏览器 warning/error 为空。截图为真实页面与实际拖画，不是 AI 目标。
6. 原版与沙画分别 TypeScript/Vite 构建，通过统一打包；保留既有 Three.js 大分块提示。平台十五页、研究三十六版本/二十七尝试/十一段录像及七十六媒体核对通过。
7. 输入、手绘存储和照片存储三个原回归文件共 12 项通过；根 `npm.cmd run check` 通过十二项目索引。
