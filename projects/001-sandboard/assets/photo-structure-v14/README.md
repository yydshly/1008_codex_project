# 单图塑形验证 · v14

2026-10-09。固定使用 [雨窗人物](../photo-memory-v12/sample-window.png)，原照为本项目此前生成的 AI 虚构场景；未使用用户照片或节目素材。本目录由项目原创材料与编排代码生成，沿用项目许可约定。

- `window-score.json`：1636 笔实际工具动作，只含曲线路径、区域、工具、预算、时长和诊断数值，没有目标厚度、成品图或图片遮罩。脸、头发、衣身、双手、杯子的规划范围由人工标注；细部路径由实际工具响应校正后选取。
- `material-proof.png`：Node 中执行完整动作后，从实际 `StageMaterial` 厚度渲染的 768 × 512 取证图。
- `target-preview.png`：照片转换的规划目标，**不是演出成品**。保留它是为了明确显示演出与目标之间的差距。
- `product-final.png`：本地生产网页在实际演出完成时的截图，含过程控件和单图边界说明。
- `product-process.png`：150.1 秒模拟时刻的真实中间帧，位于双手与杯子塑形阶段。
- `product-exhibit.png`：同一实际终态保存后的作品展映截图。
- `performance.png`、`sample-exhibition.html`：浏览器实际下载的纯沙画和默认不含原照的离线展览。

材料模拟时长 521.883 秒。网页默认 10 倍快速预览，名义观看时长约 52 秒；可改为 1 倍观察动作。实际播放耗时还受设备性能影响。每笔执行添沙 / 收沙，细流添沙后局部揉沙；其中另有四段大掌面揉沙。材料仍可接管、撤销、收藏和导出，结束时不覆盖成目标图。

视觉判断：面部明暗与捧杯姿态较 v13 更可辨，但环境仍有斑块、手指分离不足，细部依赖大量短笔触，动作还不具备沙画艺术家的自然节奏。**美术质量尚未通过目标验收；这一例不能证明任意照片自动沙画已实现。**

生成实现：`experiments/sand-art/src/memories/structured-painting.ts`。开发取证测试为 `tests/portrait-study.test.ts` 中显式启用的照片规划测试。先准备缓存 `node_modules/.cache/portrait-study/source.rgba`（原示例等比例采样为 768 × 512 的 RGBA 字节），再设置 `SAND_ART_PROOF=1` 运行该测试；这是较慢的离线规划，网页直接读取经过校验的动作谱。

参数目标为温暖、横幅、留白人像，主体 `(0.67, 0.57)`、范围 `0.34`、细节 `0.8`、反差 `1.1`、颗粒 `0.35`。误差用于指导笔触选择，不能替代视觉验收。
