# v31 · 茶杯手法小样

2026-10-10 的独立实验：先验证少量明确动作能否替代照片补图的打印感。v30 与旧模式保留。

本地入口：`http://127.0.0.1:4174/1008_codex_project/001-sandboard/art/memories/hands/contact/cup/`。原雨窗页新增“茶杯手法 · 30 秒”入口；新页可返回 v30。

## 实际能力

30 秒、1,800 个材料时间步、9 个原创主要动作：散撒台面、弯过杯底聚沙、推拢杯身亮面、细撒杯口、收出杯内光、弯撒杯把、添深右侧、落沙成碟、收亮碟沿。最后 3.5 秒等待落定。仅含几何曲线、材料力度和时间，不读取照片、目标灰度、残差或终态密度。

支持完整播放、单笔观察并自动暂停、¼ / 1 / 2 倍速度、进度定位、俯视 / 斜视 / 固定杯身近景、透光 / 侧光、实际 PNG 和完整 WebM 导出。九个动作由人编排，不是任意照片的自动转换。

## 材料原理

- 供沙沿弧长连续移动，力度渐起渐停，带低频脉动；粒包在固定出生高度按重力积分，落地后才增加沙层。
- `GroundGather.push` 以双精度暂存转移量，小步搬运接触内的已有沙，闭合台边，每步位移不超过 3.5 个网格。前缘堆积属于同一密度场，移动时不增加“已收走”。
- 接触附近的过陡坡面按 .62 坡度阈值成对松落；这是静摩擦的近似，抑制网格尖峰，质量保留在台面。
- 每次推拢结束停驻 0.25 秒，再在末端分次拾起 0.47 秒。拾起粒包离台才累计为移出；统计“台外 / 已收走”也包含散撒越界的少量材料。
- 三维沙面复用 v30 的米制颗粒与厚度透光着色，唯一输入是实际材料。共用旧材料与着色器源文件没有修改。

最终材料回归 41 文件、294 项通过、6 项显式生成 / 取证跳过；七入口 TypeScript / Vite 构建与根 12 项目核对通过。全精度材料守恒误差 .00002421，末尾无待落粒。390 × 844 下页面宽度与内容宽度均 375px，可见按钮至少 44px；新旧入口往返、单笔停止与三个收沙时刻实际验证，最终浏览器 warning/error 为空。

完整视频全片解码通过、所有帧尺寸固定；末帧与实际 PNG 的 96×64 RGB 平均误差 .0018297，属于编码色差。v30 全部 21 个已记录文件 SHA-256 逐一通过，见 `validation.json`。

初次近景检查发现沙堆产生尖角，因此增加局部坡度松落并重录。旧候选视频与截图移到本机忽略的 `node_modules/.cache/portrait-study/v31-first-*`，不是最终证据。首次动作时长测试把 26.5 秒误写成 26.6 秒，修正测试与说明后通过；总过程始终为 30 秒。

本机直接录制 WebGL 画布时，VP9 与 VP8 候选都出现解码亮部抬白，误差约 .053；仅切换编码器不能解决。最终通过明确的 sRGB 2D 表面逐帧复制同一实际画布，再 `captureStream` 录制，色差降到上述 .00183。未调色视频、修改沙量或换成预渲染动画。旧候选放忽略缓存 `v31-vp9-range.webm` / `v31-vp8-range.webm`。媒体取尾帧改为按最后解码帧时间定位，以图像管道返回非空帧，避免容器时长超出末帧时沿用旧截图。

## 复现

在 `experiments/sand-art/`：

```powershell
$env:SAND_BUILD_CUP='../../assets/cup-action-v31'
npm.cmd test -- --maxWorkers=2 tests/cup-study.test.ts
npm.cmd run build
```

显式生成命令会重写当前 v31 的验证材料，常规测试不生成。版本对照应另选新输出目录。生产构建现为七入口；发布须复制完整 `dist/`，当前没有外部发布。

媒体核对使用 `scripts/validate-cup-evidence.py --ffmpeg-dir <已有FFmpeg的bin目录>`（Python + Pillow）。脚本检查完整解码、帧尺寸、末帧 / PNG、收沙对照和所有 v30 历史哈希。
