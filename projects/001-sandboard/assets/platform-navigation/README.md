# 统一平台入口 · 2026-10-10

本轮把原版、早期创作平台和后续试验接入同一首页。页面、来源和构建说明见 [统一平台记录](../../experiments/sand-art/home/README.md)。没有改变历史效果与质量结论。

## 实际验证

- 两个独立项目通过 TypeScript / Vite 生产构建；统一打包为首页加十四功能页。保留既有 Three.js 大分块提示，无新增依赖。
- `validate-platform.mjs` 核对十五页导航接入、唯一索引、相对资源、原版同源路径、根页跳转及许可文件。
- `validate-research.mjs --built` 核对三十六版本、二十七尝试、十一录像、七十六媒体及原始文档副本；历史媒体共约 132.1 MiB，原样进入构建。
- 浏览器从项目根页进入首页，逐一打开十四个实际目录链接，页面标识、标题和返回首页路径均正确；见 `navigation-validation.json`。检查照片平台到首页、研究页到首页、全部目录到原版的实际点击。
- 原版载入完成、粗细与重置控件可用，原“沙画工作室”链接回到同源 `art/`。工作室、舞台和创作台的旧原版链接在异步初始化后均保持同源 `original/`。
- 分类“纪念短片”显示五入口，搜索 `v34` 显示一入口，无匹配词显示零入口并提供清除；清除恢复十四项。Escape 与菜单外点击关闭目录。
- 390×844 窄屏首页无横向溢出，目录可滚动到最后的研究档案链接并实际进入；没有删减手机端入口。结束时恢复正常视口。
- 本轮导航检查结束控制台 warning/error 为空。没有重新录制全部沙画或重复验收此前产品流程。
- 根 `npm.cmd run check` 通过十二项目索引核对。

## 保留核对

修改前对原版源码、沙画源码与全部既有项目素材建立 541 文件 SHA-256 清单。本轮复核 540 文件逐字节不变，唯一既有源码改动为 `web/src/style.css`：为新增顶部导航给原版固定控件让位。新增公共导航、首页、HTML 接入、构建配置、索引与文档属于本轮范围；源算法、动作谱、着色器和全部旧资产不变。结果见 `preservation.json`。新增导航不读取作品数据库，原页面按原有方式加载；未清空或迁移数据库。
