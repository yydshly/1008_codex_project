最终把过宽的横向铺沙带改成三次局部弧形撒沙。新版形成完整杯身灰阶、左侧拂光、右侧叠沙、杯口前后沿和杯底接地灰；背景没有大面积预撒噪点。大面积拾沙改为相邻粒子的显示包，避免显示数量上限导致沙量提前消失。整个成品仍由一份密度场和实际空中颗粒生成，结尾不换图。

这仍是模板数字沙画：没有自动重建照片的花纹、磨损细节，沙层和手法是近似，没有真人手或实拍素材。示例只是虚构雨窗里的杯子，不代表任意真实照片都能得到相同质量，也未达到大师作品或商业交付的完成度。

本轮来源与许可沿用项目登记，未引入新第三方素材。
