三张 PNG 为 1060 × 784 的实际画布输出。隐藏手部也会隐藏掌内沙堆，但动作、材料转移和下落沙粒仍继续计算。画面不能视为已完成的真人沙画效果。

观察：隐藏手部可以消除模型的违和感；同一沙痕在俯视和斜视中仍有明显的模糊斑块与几何边缘。当前侧视可见细小下落颗粒，但沙流起点位于画面内，隐藏手后像凭空落沙。当前隐藏手的取沙与推沙过程也会出现无可见施力源的变化。因此不能把原 24 秒完整动作序列简单隐藏手后直接当作最终作品。

建议验证的构图：固定无手俯视承担成画和作品展示；侧面近景仅在落沙阶段出现，镜头裁切让沙流从画面上缘进入。该裁切、镜头编排和改进的沙粒质感尚未实现。本次保留现有三维接触试验，不继续扩展手模型。
