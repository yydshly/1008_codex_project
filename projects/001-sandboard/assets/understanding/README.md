# Sandboard 理解总览图

2026-10-12，把源库、独立探索、实际输入输出、底层原理、产品方向与当前缺口整理为一张完整中文图版。

- [完整高清 PNG](overview.png)：3200 × 15811，七个模块，约 22.3 MiB。
- [轻量预览](preview.jpg)：1200 像素宽，研究页首次只载入此图。
- [完整文字说明](content.txt)：与图版来自同一排版内容。
- [可复现的排版文档](poster.html)：原图内嵌、中文 HTML/CSS 排版；`body` 使用 2 倍缩放。
- [输入与哈希](inputs.json)、[章节位置](layout.json)：保存素材来源、版本和渲染位置。
- [原理示意提示词](PROMPT.md)：内置 imagegen，仅生成材质概念示意；没有使用 API 或 CLI。

## 内容与来源

七个模块分别解释源库能力、输入输出、底层原理、八个探索阶段、效果问题、七类产品方向与四步产品化推进。使用十二项既有素材和一幅新增原理示意，共十四次图片展示。既有素材保留原样：原版实测、沙耙导出、v7 舞台、v11 桥、v12 风格预览、v14 照片材料、v23 三维手部、v30 无手演出、v32 / v36 海报；v8 美术目标和虚构雨窗输入照片明确标为 AI 素材。

原理插图中的网格、放大颗粒和透光是概念表达，不是源代码运行截图；程序采用高度场 / 厚度场与粒子反馈，不是逐粒完整三维物理求解。产品方向是本次归纳与建议，未把设想写成已实现能力。摄影级真人感、任意照片适配、自然连续成画和完整照片纪念短片仍需验收。

源库固定 Commit `489cb01e81b11ba575887f7c76760498eb41aaa8`，GPL-3.0-only。代码与素材许可、第三方来源继续见 [ATTRIBUTION.md](../../experiments/sand-art/ATTRIBUTION.md)。本图不改变上游许可。

## 生成与接入

在 `experiments/sand-art/` 运行 `node scripts/build-overview.mjs`，生成排版文档、文字与素材哈希。通过本机静态服务打开 `poster.html`，确认所有图片与文字后，以浏览器完整页面截图导出；原始截图返回 JPEG 编码，随后用 Sharp 转为真正 PNG，并导出轻量 JPEG 预览。文本由固定排版绘制，未交给生图模型重新书写。`layout.json` 保存同一排版的章节像素位置。

网页入口：`art/research/#overview`；首页增加快捷链接。查看器支持按章节定位、适合宽度、阅读细节、缩放、鼠标拖动与触屏滚动、高清下载、文字阅读和 Escape 关闭。高清文件只在点击放大后用于显示，关闭清除图片地址。仅新增静态资料和阅读界面，不读取或修改任何作品、草稿、原工具与成画算法。
