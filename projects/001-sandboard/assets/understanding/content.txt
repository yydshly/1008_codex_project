01

源库能力：把操作变成沙的变化源库定位是浏览器交互沙盘；照片转译、故事短片和作品管理来自我们的扩展。

原版已有 · 交互

慢划刻沟，快划扬沙输入移动方向、速度与接触范围，产生沟槽、侧向沙脊和飞沙反馈。

原版已有 · 控制

多指操作与粗细调整鼠标、触屏多指与键盘划沙；改变手指半径，持续在同一沙面上操作。

原版已有 · 体验

海浪重置与环境反馈海浪渐进抚平沙面，搭配沙声、椰树阴影与水面效果，形成可重复体验。

原版已有 · 引擎

WebGPU 实时材料计算并行更新高度场、邻域沙量和飞沙状态；渲染跟随实际状态变化。

原版已有 · 画面

高度、颗粒、光照呈现沙面高低影响法线与阴影，微颗粒补充表面细节，形成沙滩视觉。

原版已有 · 载体

可在网页中独立运行本地或静态网站运行；实时原版依赖 WebGPU、硬件加速与安全上下文。

边界：原版没有照片理解、艺术家动作编排、真人手表演或纪念短片生成。它提供交互与材料基础，作品构图和产品流程需要另行开发。

02

输入 → 制作 → 输出：两条创作路径已有路径以本机处理为主；语义识别、自动艺术编排与云端交付仍是可扩展能力。

INPUT

照片 / 手绘 / 故事上传照片、鼠标触控、示例作品、手写故事与赠言、工程 JSON。

INTERPRET

确认表达重点裁切、主体范围、明暗结构、情绪色调；当前需用户参与确认。

PLAN

构图与动作编排按大块、轮廓、细部组织曲线，设置供沙量、收沙与停顿。

MAKE

同一沙层持续变化撒、推、刮、耙、抹与收；预览、回放、手动接管和局部修画。

DELIVER

作品 / 过程 / 赠礼静帧、可编辑工程、真实帧录像、字幕海报、离线赠礼页面。

手绘创作路径操作 → 材料 → 作品。 七工具：沙耙、撒沙、推沙、刮线、心形印章、抹平、掌形。两种创作模式：沙面绘画 / 灯箱沙画。九幅工具与构图示例可直接进入原画台试画。

照片创作路径照片 → 影调预览，直接做风格转换；或 照片结构 → 动作谱 → 沙层成画，通过撒收形成作品。两条路径质量不同，预览清晰不能代替实际演出已经过关。

PNG 静帧 / 海报WebM 实际帧录像JSON 工程 / 动作记录本机收藏与草稿离线 HTML 展览 / 赠礼
输出能力分布在不同保留入口；尚未合成统一、通过视觉验收的照片纪念短片产品。MP4 交付、音乐配音、云分享与付费订单属于后续开发。

03

底层原理：材料状态、动作时间与视觉表达同一画面需要“形体正确、材料可信、动作有因果、镜头可读”一起成立。

材质概念示意 · 本次 AI 插图，不是源码截面或算法实测。中间颗粒放大展示；程序并非逐粒完整三维求解。
原版 / 手绘工作室

高度场与邻域输运每个网格保存局部沙面状态。接触把沙从沟槽搬到邻近区域，产生堆积；双缓冲并行更新，减少读写冲突。

原版基础 / 沙画扩展

供料、收沙与落回撒沙受预算、轨迹、速度与分布控制；收沙搬移或移出已有沙，飞沙再落回材料。变化应能追溯到动作。

我们的灯箱沙画

厚度决定灯箱明暗沙多遮光，沙薄透光，清出的玻璃最亮；疏密、边缘残沙、局部堆积和光照一起塑造质感。

沙量变化 = 邻域流入 − 邻域流出 + 供料 + 落回 − 移出台面的沙
材料与渲染并非同一套实现：原版及七工具工作室用 WebGPU / WGSL；舞台与部分照片产品用 CPU 厚度场 + Canvas 2D；手部接触分支增加 Three.js 三维显示。
照片规划与确定性回放：明暗概括、主体标注或手工动作谱决定曲线与沙量；固定时间步推进同一材料，用检查点回放，再记录实际画布帧。

关键认识：这是高度场 / 厚度场与粒子反馈的视觉近似。材料正确不会自动产生好的作品；它还需要构图、动作规划、渲染和审片。加噪点、加手模型或套色调都无法替代这些步骤。

05

为什么有些版本反而变差：要同时审成品与过程照片是否被认出、画面是否像沙、动作是否自然，是三个独立的检查目标。

输入：保留情绪与关系人物、雨窗、姿态和光线构成记忆。示例照片是 AI 虚构场景，真实用户照片适配仍需扩大验证。

基线：照片材料成画已有照片转译与实际过程，但轮廓、五官与灰阶仍会变软。需要与清晰预览分别验收。

退步：沙纹更强，形体更弱更强颗粒、反差与留白没有保证更好作品。杯子体积、照片内容和自然过程仍未过关。

打印感：计划过碎逐点还原明暗或反复修短笔，像扫描 / 喷绘。应先大块撒铺，再连续塑形和少量细部，留出停驻与自然修正。

模糊感：表达链丢信息照片概括、网格分辨率、动作半径和渲染都可能软化形体。优先保住主体轮廓与层次，再控制沙纹强度。

手与沙：两者必须同步漂亮手图无法自动匹配所有动作，三维可控也不等于真实。当前无手 / 局部视角可用，真人感仍未实现。

07

下一步如何产品化：先做出一段值得看的作品用同一照片基线对照版本；清晰度、沙感和撒收过程同时过关，再扩完整产品。

定作品与验收样本保留雨窗基线；收集真实人物、场景和纪念物照片，标出情绪重点与主体。固定输入比较，避免越改越偏。

验证 10–15 秒动作同一沙台：大块散撒 → 推拢 → 清出亮面 → 少量沿形细撒。能看清沙从哪里来、到哪里去。

接回完整照片短片确认构图与故事，编排成画章节、字幕和结尾赠言；可局部修画，保持预览与实际输出一致。

补齐可靠交付统一草稿、收藏和成片版本；支持横竖屏、失败恢复与通用视频格式，之后再接云分享和付费流程。

技术验收：目前有基础材料变化可回放、保存与导出；原版、各分支和草稿隔离可保留。继续检查性能、资源路径、移动端和不同浏览器的出片可靠性。

视觉验收：仍是核心缺口成品可认出主体并保留层次；疏密、堆积、透光像沙；撒收有连续因果与节奏。摄影级真实感，以及“看不出 AI / 程序生成”的目标尚未达到。

当前结论：可交互画台与照片产品已有可用基础；纪念短片已有流程原型。下一阶段最有价值的是改善实际作品和连续成画，而不是继续叠手模型、颗粒噪声或新模板数量。

来源与边界：事实来自固定上游源码、本机实验、保存的实际图片与录像；扩展方向为我们的判断。效果图保留原样，未用新美术替换历史结果。AI 输入照片、AI 美术目标及本次材质示意明确标记；三维手部不是真人实拍。
