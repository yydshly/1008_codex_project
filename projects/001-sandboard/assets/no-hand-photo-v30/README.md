# v30 · 沿形撒收与细部观看节奏

2026-10-10 原创实验；网页默认进入“沿形撒收 · 新实验”。[v29](../no-hand-photo-v29/README.md)、v28、v27 与原版谱和取证均保留。本轮没有修改 `StageMaterial` 或旧谱的执行分支；新版继续使用 v29 的清晰沙面、贴台带沙和双光线。

## 改动与实际边界

上一版细部曲线平均仅约 7.69 像素，默认细部章以 10 倍播放，42 个材料步的动作只显示约 .07 秒，易像连续盖章。本轮独立 `motion: performance`：

- `performance-curve.ts` 在原照结构目标的影调等高线附近延伸路径，并用相同方向的剩余明暗约束走向；沿节点记录渐变力度，在运行时按弧长插值。供沙/收沙不再只用每笔固定力度配一个中心高峰。目标只参与离线工具预算拟合，不进入渲染器。
- 细流更贴近沙面，大面有较高下落位置。收沙继续从已有厚度产生贴台移动颗粒，移出后才计入台外，保留 12% 薄沙脊；这不是看不见的真实手碰撞或完整粒间物理。
- 分章节奏中，细部小笔按路径长度观看 .24–.55 秒，换笔停沙 .04–.085 秒；章间停留 .8 秒。每个材料时间步完整计算，不跳步、闪现成品或覆盖终态。大灰面仍加速概括；保留 1/4/10 倍和 ¼ 倍匀速。
- 仅新版收沙颗粒显示按出生格点生成稳定的格内偏移和粒面明暗，打散整齐点阵；偏移随颗粒一起运动，不每帧重新随机。它是材料包的显示取样，不改变沙量、轨迹预算或终态。
- 新增“看细部撒沙 / 收沙”，从同一完整动作谱挑选细笔，以 ¼ 倍固定近景查看，并可导出当前片段。原塑形单笔慢动作、12 秒细看、章节定位、PNG、完整 WebM、旧芦苇和手部小样保留。

新版 1,606 笔（894 撒 / 712 收）、146,247 材料步；完整分章节奏理论 467.5900 秒。988 笔小细部曲线平均约 12.63 像素，比 v29 的 7.69 像素长约 64.4%；其中路径至少 10 像素的比例由约 24.1% 提升至 50.0%，平均仍不是几十上百像素的人工艺术长笔。最短仍约 3.06 像素，算法仍会修补局部误差。这版没有消除全部打印感，也没有将照片自动转成大师的语义手法。

## 材料与清晰度验证

完整材料回放和规划快照逐值一致，无残留空中颗粒。供料 308,196.0997、台上 271,143.4634、移出 37,052.6339，守恒在浮点累积容差内通过；58,772 步含收沙移动、80,064 步含下落供料。

原照结构目标的透光平均绝对误差：面部 .04331（v29 .04985），手杯 .04739（v29 .05288），分别减少约 13.1% / 10.4%。这只是 0–1 光量的拟合误差，不是清晰度、艺术质量或真实度评分。必须同时观察实际过程和成品。

v29 动作文件 SHA-256 保持 `9eff1f0b2b4f3ed10ef568601bf9f59d4875173cad74f30a36e98cc3a79abe0f`；旧版理论时长实际计算为 205.5789 秒，此前文档 205.63 是近似记录，执行规则未改。

## 复现

沿用 v29 缓存的 768×512 RGBA 原照，SHA-256 `81ed8b02ae057fda77804c2bbcc31be4560eecaacd13594463cd85469fc22d96`。源 PNG 在 [v12](../photo-memory-v12/README.md)，必要时先用 Pillow 的 Lanczos 缩放恢复缓存。在 `experiments/sand-art/` 运行：

```powershell
$env:SAND_BUILD_PERFORMANCE = '../../assets/no-hand-photo-v30'
npm.cmd test -- --maxWorkers=2 tests/performance-photo.test.ts
Remove-Item Env:SAND_BUILD_PERFORMANCE
npm.cmd test -- --maxWorkers=2
npm.cmd run build
npm.cmd run preview -- --host 127.0.0.1 --port 4174 --strictPort --base /1008_codex_project/001-sandboard/art/
```

显式生成会重写本版动作谱和材料报告；复现可改为新的目标目录以保留当前取证。普通测试跳过生成，验证已存新谱、旧谱校验值、细笔观看时长、力度格式和恢复检查点。首轮生成与快照校验通过，独立时长测试用了错误的旧时长估值，随后改为核对旧版实际时间表；材料与谱未因此变动。

首轮实际细部视频发现收沙样本排列成格点条纹，加入稳定显示偏移后重新核对并重录。首轮完整录像还因中段全页截图短暂改变 1 像素画布高度，导致按帧号取证的筛选器重置；最终录制期间不再截取全页，末帧用实际结束时间定位，避免误把中段当末帧。
